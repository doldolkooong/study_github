## 1단원 — 핵심 정의 🟢 ⭐

### ① 무엇인가?

DB 적재 뒤에도 자료형·집계·지역 단위·시각화를 확인해 서비스에 쓸 수 있는지 검증한다.

### ② 왜 필요한가?

DB에서 읽은 데이터의 키·자료형·결측을 검사한다. 그래프로 수치와 패턴을 재확인한 뒤 서비스 표시와 전망 가능 범위를 정한다. 이를 통해 자료형 검증에서 분석과 서비스까지 연결해 이해한다.

### ③ 쉽게 이해하기 🎨

> [!example] 비유
> 창고에 물건이 들어왔다고 끝내지 않고 품목별 재고표와 실물을 맞춰 본다.

### ④ 핵심 용어

| 용어 | 뜻과 적용 포인트 |
|---|---|
| 자료형 검증 | 숫자·날짜가 groupby·필터·시계열 연산에 적합한지 재확인한다. |
| 인구 분석 | Wide를 Long으로 바꾸고 연도별 합계 및 지역별 증감률을 계산한다. |
| 차량·면허 분석 | 차종·지역·연령별 분포와 65세 이상·자진반납 현황을 구분한다. |
| 교통사고 분석 | 지역×월, 연령×시간대, 기상상태별 집계로 서비스 질문을 검증한다. |
| 분석과 서비스 | Matplotlib 프로토타입으로 로직을 검증한 뒤 Streamlit·Plotly 화면으로 옮긴다. |

## 2단원 — 원리 / 동작 과정 🔵 ⭐

### ① 전체 흐름

1. DB에서 읽은 데이터의 키·자료형·결측을 검사한다.
2. 관측 단위를 맞춰 그룹화하고 비율 또는 증감률을 계산한다.
3. 그래프로 수치와 패턴을 재확인한 뒤 서비스 표시와 전망 가능 범위를 정한다.

### ② 왜 이렇게 동작하는가?

Wide를 Long으로 바꾸고 연도별 합계 및 지역별 증감률을 계산한다. Matplotlib 프로토타입으로 로직을 검증한 뒤 Streamlit·Plotly 화면으로 옮긴다.

### ③ 그림으로 설명


## 3단원 — 코드 / 공식 🔵 ⭐

### ① 핵심 코드

> 아래는 원문의 개념을 작은 입력으로 재구성한 학습용 예제다. 원문 코드는 하단 원문에서 확인할 수 있다.

```python
old, new = 1000, 1100
change = new-old
rate = change/old*100
print(change, rate)
```

### ② 코드 이해

| 읽는 순서 | 의미 |
|---|---|
| 입력과 전제 | DB에서 읽은 데이터의 키·자료형·결측을 검사한다. |
| 처리 | 관측 단위를 맞춰 그룹화하고 비율 또는 증감률을 계산한다. |
| 결과 | 기준 인구 1000에서 1100이면 100명 증가, 증가율 10%다. 기준값이 0이면 같은 계산을 그대로 쓰지 않는다. |

### ③ 실행 결과

**예상 결과·해석 기준 — 실제 환경 실행 결과와 구분**

```text
100 10.0
```

### ④ 결과 해석

기준 인구 1000에서 1100이면 100명 증가, 증가율 10%다. 기준값이 0이면 같은 계산을 그대로 쓰지 않는다.
