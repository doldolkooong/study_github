## 1단원 — 핵심 정의 🟢 ⭐

### ① 무엇인가?

사람이 보기 편한 공공데이터 파일을 일관된 관측 단위의 분석용 표로 바꾼다.

### ② 왜 필요한가?

파일별 헤더·병합 셀·집계 수준을 먼저 확인한다. melt로 구조를 통일하고 컬럼·키·총량을 검증한다. 이를 통해 다중 헤더에서 데이터별 목적까지 연결해 이해한다.

### ③ 쉽게 이해하기 🎨

### ④ 핵심 용어

| 용어 | 뜻과 적용 포인트 |
|---|---|
| 다중 헤더 | 병합된 연도·분류 라벨을 복원하고 제목·설명 행을 분리한다. |
| 숫자와 날짜 | 쉼표·공백을 정리하고 to_numeric·to_datetime으로 변환한다. |
| Wide와 Long | 여러 연도 열을 year와 value로 바꿔 그룹 분석과 DB 저장을 쉽게 한다. |
| 총계와 상세 | 합계·소계를 상세 행과 함께 더하지 않도록 구분한다. |
| 데이터별 목적 | 사고는 건수·사망·부상을 구분하고 정책은 문자열·날짜, FAQ는 질문·답변·URL을 정리한다. |

## 2단원 — 원리 / 동작 과정 🔵 ⭐

### ① 전체 흐름

1. 파일별 헤더·병합 셀·집계 수준을 먼저 확인한다.
2. 필요한 행·열을 고르고 라벨 복원·문자 정리·형변환을 수행한다.
3. melt로 구조를 통일하고 컬럼·키·총량을 검증한다.

### ② 왜 이렇게 동작하는가?

쉼표·공백을 정리하고 to_numeric·to_datetime으로 변환한다. 사고는 건수·사망·부상을 구분하고 정책은 문자열·날짜, FAQ는 질문·답변·URL을 정리한다.

## 3단원 — 코드 / 공식 🔵 ⭐

### ① 핵심 코드

> 아래는 원문의 개념을 작은 입력으로 재구성한 학습용 예제다. 원문 코드는 하단 원문에서 확인할 수 있다.

```python
import pandas as pd
wide = pd.DataFrame({'region':['Seoul'], '2024':['1,000'], '2025':['1,100']})
long = wide.melt(id_vars='region', var_name='year', value_name='population')
long['population'] = pd.to_numeric(long['population'].str.replace(',', '', regex=False))
print(long['population'].tolist())
```

### ② 코드 이해

| 읽는 순서 | 의미 |
|---|---|
| 입력과 전제 | 파일별 헤더·병합 셀·집계 수준을 먼저 확인한다. |
| 처리 | 필요한 행·열을 고르고 라벨 복원·문자 정리·형변환을 수행한다. |
| 결과 | 연도별 두 컬럼이 두 행으로 바뀌었고 문자열 인구수가 계산 가능한 숫자가 되었다. |
