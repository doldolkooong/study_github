# 013. 약수 구하기

## <문제>

> 정수 n의 약수를 오름차순으로 담은 배열을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(n)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 정수 n의 약수를 오름차순으로 담은 배열을 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `24` | `[1,2,3,4,6,8,12,24]` |
| `29` | `[1,29]` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(n):
    result = []
    for i in range(1, n + 1):
        if n % i == 0:
            result.append(i)
    return result
```

### 수정한 코드 / 최종 코드

제공한 풀이의 핵심 로직을 그대로 사용한다.

```python
def solution(n):
    result = []
    for i in range(1, n + 1):
        if n % i == 0:
            result.append(i)
    return result
```

## <해설>

### 문제 핵심

- 구할 값: 정수 n의 약수를 오름차순으로 담은 배열을 반환하세요.
- 핵심 문법: **나머지 · 약수**
- 주의할 조건: 0으로 나누지 않도록 1부터 시작한다. n%i와 i%n을 혼동하지 않는다. 작은 수부터 확인하므로 정렬이 필요 없다.

### 풀이 순서

1. 1부터 n까지 순회.
2. n%i가 0인지 확인.
3. 약수 i를 추가.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 1부터 n까지 순회 |
| 2단계 | n%i가 0인지 확인 |
| 3단계 | 약수 i를 추가 |

### 왜 이렇게 풀었는가?

1부터 n까지 순회 → n%i가 0인지 확인 → 약수 i를 추가. 0으로 나누지 않도록 1부터 시작한다. n%i와 i%n을 혼동하지 않는다. 작은 수부터 확인하므로 정렬이 필요 없다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 0으로 나누지 않도록 1부터 시작한다. n%i와 i%n을 혼동하지 않는다. 작은 수부터 확인하므로 정렬이 필요 없다.

### 기억할 것

- 나머지 · 약수
- 첫 예시 `24`를 손으로 따라가며 `[1,2,3,4,6,8,12,24]`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
