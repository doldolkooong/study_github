# 016. 배열의 유사도

## <문제>

> 문자열 배열 s1과 s2에 같은 원소가 몇 개 있는지 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(s1, s2)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 문자열 배열 s1과 s2에 같은 원소가 몇 개 있는지 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `["a","b","c"], ["com","b","d","p","c"]` | `2` |
| `["n","omg"], ["m","dot"]` | `0` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(s1, s2):
    count = 0
    for i in range(len(s1)):
        if s1[i] in s2:
            count += 1
    return count
```

### 수정한 코드 / 최종 코드

제공한 풀이의 핵심 로직을 그대로 사용한다.

```python
def solution(s1, s2):
    count = 0
    for i in range(len(s1)):
        if s1[i] in s2:
            count += 1
    return count
```

## <해설>

### 문제 핵심

- 구할 값: 문자열 배열 s1과 s2에 같은 원소가 몇 개 있는지 반환하세요.
- 핵심 문법: **멤버십 in · 개수 세기**
- 주의할 조건: 제공 코드에서 s1의 중복은 여러 번 센다. 중복이 허용되는 일반 문제로 확장하면 집합 교집합과 뜻이 달라질 수 있다.

### 풀이 순서

1. s1 원소 순회.
2. s2에 포함되는지 확인.
3. 공통 원소 수 누적.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | s1 원소 순회 |
| 2단계 | s2에 포함되는지 확인 |
| 3단계 | 공통 원소 수 누적 |

### 왜 이렇게 풀었는가?

s1 원소 순회 → s2에 포함되는지 확인 → 공통 원소 수 누적. 제공 코드에서 s1의 중복은 여러 번 센다. 중복이 허용되는 일반 문제로 확장하면 집합 교집합과 뜻이 달라질 수 있다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 제공 코드에서 s1의 중복은 여러 번 센다. 중복이 허용되는 일반 문제로 확장하면 집합 교집합과 뜻이 달라질 수 있다.

### 기억할 것

- 멤버십 in · 개수 세기
- 첫 예시 `["a","b","c"], ["com","b","d","p","c"]`를 손으로 따라가며 `2`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
