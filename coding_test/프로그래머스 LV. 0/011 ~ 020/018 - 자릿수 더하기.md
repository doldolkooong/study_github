# 018. 자릿수 더하기

## <문제>

> 정수 n의 각 자리 숫자의 합을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(n)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 정수 n의 각 자리 숫자의 합을 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `1234` | `10` |
| `930211` | `16` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(n):
    n = str(n)   # 자리별로 접근하기 위해 문자열로 변환
    result = 0
    for i in range(len(n)):
        result += int(n[i])
    return result
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(n):
    return sum(int(digit) for digit in str(n))
```

## <해설>

### 문제 핵심

- 구할 값: 정수 n의 각 자리 숫자의 합을 반환하세요.
- 핵심 문법: **str · int · 자릿수**
- 주의할 조건: 정수 n 전체를 더하는 것이 아니다. 음수의 '-' 문자를 처리하는 기능은 포함하지 않은 풀이이다.

### 풀이 순서

1. 정수를 문자열로 변환.
2. 각 문자를 정수로 변환.
3. 자리별 값을 누적.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 정수를 문자열로 변환 |
| 2단계 | 각 문자를 정수로 변환 |
| 3단계 | 자리별 값을 누적 |

### 왜 이렇게 풀었는가?

정수를 문자열로 변환 → 각 문자를 정수로 변환 → 자리별 값을 누적. 정수 n 전체를 더하는 것이 아니다. 음수의 '-' 문자를 처리하는 기능은 포함하지 않은 풀이이다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 정수 n 전체를 더하는 것이 아니다. 음수의 '-' 문자를 처리하는 기능은 포함하지 않은 풀이이다.

### 기억할 것

- str · int · 자릿수
- 첫 예시 `1234`를 손으로 따라가며 `10`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
