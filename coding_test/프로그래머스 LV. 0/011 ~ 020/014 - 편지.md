# 014. 편지

## <문제>

> message를 글자 한 자당 가로 2cm로 적으려 합니다. 가로로만 쓸 때 필요한 편지지의 최소 가로길이를 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(message)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- message를 글자 한 자당 가로 2cm로 적으려 합니다. 가로로만 쓸 때 필요한 편지지의 최소 가로길이를 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `"happy birthday!"` | `30` |
| `"I love you~"` | `22` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(message):
    return 2 * len(message)  # 글자 수 × 2cm
```

### 수정한 코드 / 최종 코드

제공한 풀이의 핵심 로직을 그대로 사용한다.

```python
def solution(message):
    return 2 * len(message)  # 글자 수 × 2cm
```

---

## <해설>

### 문제 핵심

- 구할 값: message를 글자 한 자당 가로 2cm로 적으려 합니다. 가로로만 쓸 때 필요한 편지지의 최소 가로길이를 반환하세요.
- 핵심 문법: **len · 단위당 크기**
- 주의할 조건: 공백과 느낌표·물결표도 한 문자로 센다.

### 풀이 순서

1. 전체 문자 수 확인.
2. 문자당 2cm 곱함.
3. 가로길이 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 전체 문자 수 확인 |
| 2단계 | 문자당 2cm 곱함 |
| 3단계 | 가로길이 반환 |

### 왜 이렇게 풀었는가?

전체 문자 수 확인 → 문자당 2cm 곱함 → 가로길이 반환. 공백과 느낌표·물결표도 한 문자로 센다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 공백과 느낌표·물결표도 한 문자로 센다.

### 기억할 것

- len · 단위당 크기
- 첫 예시 `"happy birthday!"`를 손으로 따라가며 `30`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
