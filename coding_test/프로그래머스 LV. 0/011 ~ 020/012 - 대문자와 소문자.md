# 012. 대문자와 소문자

## <문제>

> 문자열 my_string의 대문자는 소문자로, 소문자는 대문자로 변환하여 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(my_string)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 문자열 my_string의 대문자는 소문자로, 소문자는 대문자로 변환하여 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `"cccCCC"` | `"CCCccc"` |
| `"abCdEfghIJ"` | `"ABcDeFGHij"` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(my_string):
    answer = []
    my_string = list(my_string)
    for i in range(len(my_string)):
        if my_string[i].isupper():
            answer.append(my_string[i].lower())
        else:
            answer.append(my_string[i].upper())
    return "".join(answer)
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(my_string):
    return my_string.swapcase()
```

## <해설>

### 문제 핵심

- 구할 값: 문자열 my_string의 대문자는 소문자로, 소문자는 대문자로 변환하여 반환하세요.
- 핵심 문법: **isupper · upper · lower · swapcase**
- 주의할 조건: 전체를 lower로 통일하는 문제와 다르다. 각 문자의 대소문자를 서로 뒤집는다.

### 풀이 순서

1. 문자의 대문자 여부 검사.
2. 반대 대소문자로 변환.
3. 문자열로 합침.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 문자의 대문자 여부 검사 |
| 2단계 | 반대 대소문자로 변환 |
| 3단계 | 문자열로 합침 |

### 왜 이렇게 풀었는가?

문자의 대문자 여부 검사 → 반대 대소문자로 변환 → 문자열로 합침. 전체를 lower로 통일하는 문제와 다르다. 각 문자의 대소문자를 서로 뒤집는다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 전체를 lower로 통일하는 문제와 다르다. 각 문자의 대소문자를 서로 뒤집는다.

### 기억할 것

- isupper · upper · lower · swapcase
- 첫 예시 `"cccCCC"`를 손으로 따라가며 `"CCCccc"`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
