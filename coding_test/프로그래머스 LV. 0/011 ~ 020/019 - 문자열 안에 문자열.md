# 019. 문자열 안에 문자열

## <문제>

> 문자열 str1 안에 str2가 있으면 1, 없으면 2를 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(str1, str2)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 문자열 str1 안에 str2가 있으면 1, 없으면 2를 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `"ab6CDE443fgh22iJKlmn1o", "6CD"` | `1` |
| `"ppprrrogrammers", "pppp"` | `2` |
| `"AbcAbcA", "AAA"` | `2` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(str1, str2):
    if str2 in str1:
        return 1
    else:
        return 2
```

### 수정한 코드 / 최종 코드

제공한 풀이의 핵심 로직을 그대로 사용한다.

```python
def solution(str1, str2):
    if str2 in str1:
        return 1
    else:
        return 2
```

## <해설>

### 문제 핵심

- 구할 값: 문자열 str1 안에 str2가 있으면 1, 없으면 2를 반환하세요.
- 핵심 문법: **문자열 in · 부분 문자열**
- 주의할 조건: 문자가 흩어져 있는 것이 아니라 연속된 부분 문자열이어야 한다. 대소문자도 구분한다.

### 풀이 순서

1. str2 포함 여부 확인.
2. 있으면 1 반환.
3. 없으면 2 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | str2 포함 여부 확인 |
| 2단계 | 있으면 1 반환 |
| 3단계 | 없으면 2 반환 |

### 왜 이렇게 풀었는가?

str2 포함 여부 확인 → 있으면 1 반환 → 없으면 2 반환. 문자가 흩어져 있는 것이 아니라 연속된 부분 문자열이어야 한다. 대소문자도 구분한다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 문자가 흩어져 있는 것이 아니라 연속된 부분 문자열이어야 한다. 대소문자도 구분한다.

### 기억할 것

- 문자열 in · 부분 문자열
- 첫 예시 `"ab6CDE443fgh22iJKlmn1o", "6CD"`를 손으로 따라가며 `1`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
