# 011. 삼각형의 완성조건(1)

## <문제>

> 세 변 sides로 삼각형을 만들 수 있으면 1, 없으면 2를 반환하세요. 가장 긴 변은 다른 두 변의 길이 합보다 작아야 합니다.

### 입력 / 조건

- 함수 선언: `solution(sides)`
- sides에는 세 변의 길이가 담겨 있다.

### 출력 / 요구사항

- 세 변 sides로 삼각형을 만들 수 있으면 1, 없으면 2를 반환하세요. 가장 긴 변은 다른 두 변의 길이 합보다 작아야 합니다.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `[1,2,3]` | `2` |
| `[3,6,2]` | `2` |
| `[199,72,222]` | `1` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(sides):
    sides.sort(reverse=False)
    if sides[2] < sides[0] + sides[1]:
        return 1
    else:
        return 2
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(sides):
    a, b, c = sorted(sides)
    return 1 if a + b > c else 2
```

## <해설>

### 문제 핵심

- 구할 값: 세 변 sides로 삼각형을 만들 수 있으면 1, 없으면 2를 반환하세요. 가장 긴 변은 다른 두 변의 길이 합보다 작아야 합니다.
- 핵심 문법: **정렬 · 엄격 부등식**
- 주의할 조건: 두 변의 합과 가장 긴 변이 같아도 삼각형은 아니다. sort는 원본을 바꾸고 sorted는 새 리스트를 만든다.

### 풀이 순서

1. 세 변 정렬.
2. 작은 두 변의 합 비교.
3. 가장 긴 변보다 크면 1 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 세 변 정렬 |
| 2단계 | 작은 두 변의 합 비교 |
| 3단계 | 가장 긴 변보다 크면 1 반환 |

### 왜 이렇게 풀었는가?

세 변 정렬 → 작은 두 변의 합 비교 → 가장 긴 변보다 크면 1 반환. 두 변의 합과 가장 긴 변이 같아도 삼각형은 아니다. sort는 원본을 바꾸고 sorted는 새 리스트를 만든다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 두 변의 합과 가장 긴 변이 같아도 삼각형은 아니다. sort는 원본을 바꾸고 sorted는 새 리스트를 만든다.

### 기억할 것

- 정렬 · 엄격 부등식
- 첫 예시 `[1,2,3]`를 손으로 따라가며 `2`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
