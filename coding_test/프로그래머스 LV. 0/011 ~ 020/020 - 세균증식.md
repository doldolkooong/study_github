# 020. 세균증식

## <문제>

> 어떤 세균은 1시간마다 두 배로 증식합니다. 처음 세균 수 n과 경과 시간 t가 주어질 때 t시간 후 세균 수를 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(n, t)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 어떤 세균은 1시간마다 두 배로 증식합니다. 처음 세균 수 n과 경과 시간 t가 주어질 때 t시간 후 세균 수를 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `2, 10` | `2048` |
| `7, 15` | `229376` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(n, t):
    return n * (2 ** t)  # 초기값 × 2의 t제곱
```

### 수정한 코드 / 최종 코드

제공한 풀이의 핵심 로직을 그대로 사용한다.

```python
def solution(n, t):
    return n * (2 ** t)  # 초기값 × 2의 t제곱
```

## <해설>

### 문제 핵심

- 구할 값: 어떤 세균은 1시간마다 두 배로 증식합니다. 처음 세균 수 n과 경과 시간 t가 주어질 때 t시간 후 세균 수를 반환하세요.
- 핵심 문법: **거듭제곱 ** · 지수 증가**
- 주의할 조건: 2*t는 선형 증가이고 2**t는 거듭제곱이다. Python에서 ^는 거듭제곱 연산자가 아니다.

### 풀이 순서

1. 시간당 배율 2 확인.
2. t번 증가를 2**t로 계산.
3. 초기 수 n을 곱함.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 시간당 배율 2 확인 |
| 2단계 | t번 증가를 2**t로 계산 |
| 3단계 | 초기 수 n을 곱함 |

### 왜 이렇게 풀었는가?

시간당 배율 2 확인 → t번 증가를 2**t로 계산 → 초기 수 n을 곱함. 2*t는 선형 증가이고 2**t는 거듭제곱이다. Python에서 ^는 거듭제곱 연산자가 아니다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 2*t는 선형 증가이고 2**t는 거듭제곱이다. Python에서 ^는 거듭제곱 연산자가 아니다.

### 기억할 것

- 거듭제곱 ** · 지수 증가
- 첫 예시 `2, 10`를 손으로 따라가며 `2048`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
