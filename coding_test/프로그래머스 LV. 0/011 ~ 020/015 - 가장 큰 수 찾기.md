# 015. 가장 큰 수 찾기

## <문제>

> 정수 배열 array의 가장 큰 수와 그 수의 인덱스를 담은 배열을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(array)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 정수 배열 array의 가장 큰 수와 그 수의 인덱스를 담은 배열을 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `[1,8,3]` | `[8,1]` |
| `[9,10,11,8]` | `[11,2]` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(array):
    return [max(array), array.index(max(array))]
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(array):
    largest = max(array)
    return [largest, array.index(largest)]
```

---

## <해설>

### 문제 핵심

- 구할 값: 정수 배열 array의 가장 큰 수와 그 수의 인덱스를 담은 배열을 반환하세요.
- 핵심 문법: **max · index**
- 주의할 조건: 인덱스는 0부터 센다. 같은 최댓값이 여러 개라면 index는 첫 위치를 반환한다. max 계산을 변수에 저장하면 반복 호출을 줄인다.

### 풀이 순서

1. max로 최댓값 계산.
2. index로 위치 확인.
3. [값, 인덱스] 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | max로 최댓값 계산 |
| 2단계 | index로 위치 확인 |
| 3단계 | [값, 인덱스] 반환 |

### 왜 이렇게 풀었는가?

max로 최댓값 계산 → index로 위치 확인 → [값, 인덱스] 반환. 인덱스는 0부터 센다. 같은 최댓값이 여러 개라면 index는 첫 위치를 반환한다. max 계산을 변수에 저장하면 반복 호출을 줄인다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 인덱스는 0부터 센다. 같은 최댓값이 여러 개라면 index는 첫 위치를 반환한다. max 계산을 변수에 저장하면 반복 호출을 줄인다.

### 기억할 것

- max · index
- 첫 예시 `[1,8,3]`를 손으로 따라가며 `[8,1]`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
