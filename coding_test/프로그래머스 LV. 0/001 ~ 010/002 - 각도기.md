# 002. 각도기

## <문제>

> 0도 초과 90도 미만은 예각(1), 90도는 직각(2), 90도 초과 180도 미만은 둔각(3), 180도는 평각(4)입니다. angle에 맞는 번호를 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(angle)`
- 각도 범위와 반환값: 예각 1 / 직각 2 / 둔각 3 / 평각 4.

### 출력 / 요구사항

- 0도 초과 90도 미만은 예각(1), 90도는 직각(2), 90도 초과 180도 미만은 둔각(3), 180도는 평각(4)입니다. angle에 맞는 번호를 반환하세요.

### 예시

아래는 이해를 돕기 위해 추가한 예시다.

| 입력 | 결과 |
|---|---|
| `70` | `1` |
| `90` | `2` |
| `120` | `3` |
| `180` | `4` |

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(angle):
    if 0 < angle < 90:
        return 1
    elif angle == 90:
        return 2
    elif 90 < angle < 180:
        return 3
    else:  # 문제의 각도 범위에서 180도
        return 4
```

## <해설>

### 문제 핵심

- 구할 값: 0도 초과 90도 미만은 예각(1), 90도는 직각(2), 90도 초과 180도 미만은 둔각(3), 180도는 평각(4)입니다. angle에 맞는 번호를 반환하세요.
- 핵심 문법: **조건문 · 경계값**
- 주의할 조건: else가 180도를 의미하는 것은 입력이 0도 초과 180도 이하라는 전제에서다. 90과 180의 경계를 구분한다.

### 풀이 순서

1. 예각 범위 확인.
2. 직각·둔각 여부 확인.
3. 평각이면 4 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 예각 범위 확인 |
| 2단계 | 직각·둔각 여부 확인 |
| 3단계 | 평각이면 4 반환 |

### 왜 이렇게 풀었는가?

예각 범위 확인 → 직각·둔각 여부 확인 → 평각이면 4 반환. else가 180도를 의미하는 것은 입력이 0도 초과 180도 이하라는 전제에서다. 90과 180의 경계를 구분한다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- else가 180도를 의미하는 것은 입력이 0도 초과 180도 이하라는 전제에서다. 90과 180의 경계를 구분한다.

### 기억할 것

- 조건문 · 경계값
- 첫 예시 `70`를 손으로 따라가며 `1`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
