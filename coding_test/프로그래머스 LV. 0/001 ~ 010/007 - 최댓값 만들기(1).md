# 007. 최댓값 만들기(1)

## <문제>

> 정수 배열 numbers의 서로 다른 두 위치에서 원소를 골라 곱했을 때 만들 수 있는 최댓값을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(numbers)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 정수 배열 numbers의 서로 다른 두 위치에서 원소를 골라 곱했을 때 만들 수 있는 최댓값을 반환하세요.

### 예시

아래는 이해를 돕기 위해 추가한 예시다.

| 입력 | 결과 |
|---|---|
| `[1,2,3,4,5]` | `20` |
| `[0,31,24,10,1,9]` | `744` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(numbers):
    result = []
    for i in range(len(numbers)):
        for j in range(i + 1, len(numbers)):
            result.append(numbers[i] * numbers[j])
    return max(result)
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(numbers):
    best = numbers[0] * numbers[1]
    for i in range(len(numbers)):
        for j in range(i + 1, len(numbers)):
            best = max(best, numbers[i] * numbers[j])
    return best
```

## <해설>

### 문제 핵심

- 구할 값: 정수 배열 numbers의 서로 다른 두 위치에서 원소를 골라 곱했을 때 만들 수 있는 최댓값을 반환하세요.
- 핵심 문법: **완전탐색 · 이중 반복**
- 주의할 조건: j=i+1부터 시작하면 같은 위치를 두 번 사용하지 않고 쌍도 중복하지 않는다. 개선 코드는 모든 곱을 저장하지 않고 최대만 유지한다. 최소 2개 원소가 필요하다.

### 풀이 순서

1. 첫 위치 i 선택.
2. i 뒤의 j 선택.
3. 모든 곱의 최댓값 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 첫 위치 i 선택 |
| 2단계 | i 뒤의 j 선택 |
| 3단계 | 모든 곱의 최댓값 반환 |

### 왜 이렇게 풀었는가?

첫 위치 i 선택 → i 뒤의 j 선택 → 모든 곱의 최댓값 반환. j=i+1부터 시작하면 같은 위치를 두 번 사용하지 않고 쌍도 중복하지 않는다. 개선 코드는 모든 곱을 저장하지 않고 최대만 유지한다. 최소 2개 원소가 필요하다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- j=i+1부터 시작하면 같은 위치를 두 번 사용하지 않고 쌍도 중복하지 않는다. 개선 코드는 모든 곱을 저장하지 않고 최대만 유지한다. 최소 2개 원소가 필요하다.

### 기억할 것

- 완전탐색 · 이중 반복
- 첫 예시 `[1,2,3,4,5]`를 손으로 따라가며 `20`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
