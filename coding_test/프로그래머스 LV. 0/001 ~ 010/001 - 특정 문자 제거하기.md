# 001. 특정 문자 제거하기

## <문제>

> 문자열 my_string과 문자 letter가 매개변수로 주어집니다. my_string에서 letter를 제거한 문자열을 return하도록 solution 함수를 완성해주세요.

### 입력 / 조건

- 함수 선언: `solution(my_string, letter)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 문자열 my_string과 문자 letter가 매개변수로 주어집니다. my_string에서 letter를 제거한 문자열을 return하도록 solution 함수를 완성해주세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `"abcdef", "f"` | `"abcde"` |
| `"BCBdbe", "B"` | `"Cdbe"` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(my_string, letter):
    my_string = list(my_string)  # 문자 하나하나 다루기 위해 리스트로 변환
    result = []
    for i in range(len(my_string)):
        if my_string[i] != letter:
            result.append(my_string[i])
    return "".join(result)
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(my_string, letter):
    return my_string.replace(letter, "")
```

## <해설>

### 문제 핵심

- 구할 값: 문자열 my_string과 문자 letter가 매개변수로 주어집니다. my_string에서 letter를 제거한 문자열을 return하도록 solution 함수를 완성해주세요.
- 핵심 문법: **문자 필터링 · replace · join**
- 주의할 조건: 대소문자를 구분한다. 문자열도 직접 순회할 수 있어 리스트 변환은 필수가 아니다.

### 풀이 순서

1. 각 문자를 확인.
2. letter와 다른 문자만 저장.
3. join으로 문자열 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 각 문자를 확인 |
| 2단계 | letter와 다른 문자만 저장 |
| 3단계 | join으로 문자열 반환 |

### 왜 이렇게 풀었는가?

각 문자를 확인 → letter와 다른 문자만 저장 → join으로 문자열 반환. 대소문자를 구분한다. 문자열도 직접 순회할 수 있어 리스트 변환은 필수가 아니다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 대소문자를 구분한다. 문자열도 직접 순회할 수 있어 리스트 변환은 필수가 아니다.

### 기억할 것

- 문자 필터링 · replace · join
- 첫 예시 `"abcdef", "f"`를 손으로 따라가며 `"abcde"`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
