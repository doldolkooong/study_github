# 006. 점의 위치 구하기

## <문제>

> dot=[x,y]가 주어집니다. x·y가 모두 양수이면 1, x가 음수·y가 양수이면 2, 둘 다 음수이면 3, x가 양수·y가 음수이면 4사분면입니다. 해당 번호를 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(dot)`
- dot[0]은 x 좌표, dot[1]은 y 좌표다.

### 출력 / 요구사항

- dot=[x,y]가 주어집니다. x·y가 모두 양수이면 1, x가 음수·y가 양수이면 2, 둘 다 음수이면 3, x가 양수·y가 음수이면 4사분면입니다. 해당 번호를 반환하세요.

### 예시

아래는 이해를 돕기 위해 추가한 예시다.

| 입력 | 결과 |
|---|---|
| `[2,4]` | `1` |
| `[-7,9]` | `2` |
| `[-3,-2]` | `3` |
| `[2,-4]` | `4` |

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(dot):
    if dot[0] > 0 and dot[1] > 0:
        return 1
    if dot[0] > 0 and dot[1] < 0:
        return 4
    if dot[0] < 0 and dot[1] > 0:
        return 2
    if dot[0] < 0 and dot[1] < 0:
        return 3
```

## <해설>

### 문제 핵심

- 구할 값: dot=[x,y]가 주어집니다. x·y가 모두 양수이면 1, x가 음수·y가 양수이면 2, 둘 다 음수이면 3, x가 양수·y가 음수이면 4사분면입니다. 해당 번호를 반환하세요.
- 핵심 문법: **논리 연산 and · 부호**
- 주의할 조건: 축 위의 점은 사분면에 속하지 않는다. 제공 코드에는 x=0 또는 y=0일 때의 반환이 없다.

### 풀이 순서

1. x의 부호 확인.
2. y의 부호와 조합.
3. 사분면 번호 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | x의 부호 확인 |
| 2단계 | y의 부호와 조합 |
| 3단계 | 사분면 번호 반환 |

### 왜 이렇게 풀었는가?

x의 부호 확인 → y의 부호와 조합 → 사분면 번호 반환. 축 위의 점은 사분면에 속하지 않는다. 제공 코드에는 x=0 또는 y=0일 때의 반환이 없다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 축 위의 점은 사분면에 속하지 않는다. 제공 코드에는 x=0 또는 y=0일 때의 반환이 없다.

### 기억할 것

- 논리 연산 and · 부호
- 첫 예시 `[2,4]`를 손으로 따라가며 `1`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
