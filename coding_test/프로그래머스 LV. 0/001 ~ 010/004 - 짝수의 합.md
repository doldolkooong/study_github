# 004. 짝수의 합

## <문제>

> 정수 n이 주어질 때, n 이하의 짝수를 모두 더한 값을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(n)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 정수 n이 주어질 때, n 이하의 짝수를 모두 더한 값을 반환하세요.

### 예시

아래는 이해를 돕기 위해 추가한 예시다.

| 입력 | 결과 |
|---|---|
| `10` | `30` |
| `4` | `6` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(n):
    answer = 0
    for i in range(1, n + 1):
        if i % 2 == 0:
            answer += i
    return answer
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(n):
    return sum(range(2, n + 1, 2))
```

## <해설>

### 문제 핵심

- 구할 값: 정수 n이 주어질 때, n 이하의 짝수를 모두 더한 값을 반환하세요.
- 핵심 문법: **나머지 · 누적 합 · range**
- 주의할 조건: range의 끝은 제외되므로 n을 포함하려면 n+1을 사용한다. 간격을 2로 두면 짝수만 순회한다.

### 풀이 순서

1. 1부터 n까지 순회.
2. 2로 나누어떨어지는 수 선택.
3. 누적 합 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 1부터 n까지 순회 |
| 2단계 | 2로 나누어떨어지는 수 선택 |
| 3단계 | 누적 합 반환 |

### 왜 이렇게 풀었는가?

1부터 n까지 순회 → 2로 나누어떨어지는 수 선택 → 누적 합 반환. range의 끝은 제외되므로 n을 포함하려면 n+1을 사용한다. 간격을 2로 두면 짝수만 순회한다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- range의 끝은 제외되므로 n을 포함하려면 n+1을 사용한다. 간격을 2로 두면 짝수만 순회한다.

### 기억할 것

- 나머지 · 누적 합 · range
- 첫 예시 `10`를 손으로 따라가며 `30`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
