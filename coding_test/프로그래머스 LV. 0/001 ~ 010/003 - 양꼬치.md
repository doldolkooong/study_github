# 003. 양꼬치

## <문제>

> 양꼬치는 1인분에 12,000원, 음료수는 2,000원입니다. 양꼬치 10인분마다 음료수 하나를 서비스로 줍니다. n인분과 음료수 k개의 총 지불 금액을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(n, k)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 양꼬치는 1인분에 12,000원, 음료수는 2,000원입니다. 양꼬치 10인분마다 음료수 하나를 서비스로 줍니다. n인분과 음료수 k개의 총 지불 금액을 반환하세요.

### 예시

아래는 이해를 돕기 위해 추가한 예시다.

| 입력 | 결과 |
|---|---|
| `n=10, k=3` | `124000` |
| `n=64, k=6` | `768000` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(n, k):
    sheep_price = n * 12000
    drink_price = k * 2000
    total = 0
    if n >= 10:
        total = sheep_price - (n // 10 * 2000) + drink_price
    else:
        total = sheep_price + drink_price
    return total
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(n, k):
    return n * 12000 - n // 10 * 2000 + k * 2000
```

## <해설>

### 문제 핵심

- 구할 값: 양꼬치는 1인분에 12,000원, 음료수는 2,000원입니다. 양꼬치 10인분마다 음료수 하나를 서비스로 줍니다. n인분과 음료수 k개의 총 지불 금액을 반환하세요.
- 핵심 문법: **정수 나눗셈 · 가격 계산**
- 주의할 조건: n이 10 미만이면 n//10은 0이라 별도 분기가 필요 없다. 무료 음료 수가 주문 음료 수를 넘지 않는 입력을 전제로 한 코드다.

### 풀이 순서

1. 양꼬치 가격 계산.
2. n//10으로 무료 음료 수 계산.
3. 전체 음료 금액에서 서비스 금액 차감.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 양꼬치 가격 계산 |
| 2단계 | n//10으로 무료 음료 수 계산 |
| 3단계 | 전체 음료 금액에서 서비스 금액 차감 |

### 왜 이렇게 풀었는가?

양꼬치 가격 계산 → n//10으로 무료 음료 수 계산 → 전체 음료 금액에서 서비스 금액 차감. n이 10 미만이면 n//10은 0이라 별도 분기가 필요 없다. 무료 음료 수가 주문 음료 수를 넘지 않는 입력을 전제로 한 코드다.

- n이 10 미만이면 n//10은 0이라 별도 분기가 필요 없다. 무료 음료 수가 주문 음료 수를 넘지 않는 입력을 전제로 한 코드다.
