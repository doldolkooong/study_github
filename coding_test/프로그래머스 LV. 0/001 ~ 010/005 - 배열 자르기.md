# 005. 배열 자르기

## <문제>

> 정수 배열 numbers에서 num1번째 인덱스부터 num2번째 인덱스까지 자른 배열을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(numbers, num1, num2)`
- num1·num2는 인덱스이며 양 끝 원소를 모두 포함한다.

### 출력 / 요구사항

- 정수 배열 numbers에서 num1번째 인덱스부터 num2번째 인덱스까지 자른 배열을 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `[1,2,3,4,5], 1, 3` | `[2,3,4]` |
| `[1,3,5], 1, 2` | `[3,5]` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(numbers, num1, num2):
    return numbers[num1:num2 + 1]  # num2를 포함해야 하므로 +1
```

### 수정한 코드 / 최종 코드

제공한 풀이의 핵심 로직을 그대로 사용한다.

```python
def solution(numbers, num1, num2):
    return numbers[num1:num2 + 1]  # num2를 포함해야 하므로 +1
```

## <해설>

### 문제 핵심

- 구할 값: 정수 배열 numbers에서 num1번째 인덱스부터 num2번째 인덱스까지 자른 배열을 반환하세요.
- 핵심 문법: **슬라이싱 · 인덱스**
- 주의할 조건: 문제의 끝 인덱스는 포함하지만 슬라이싱의 stop은 제외한다.

### 풀이 순서

1. 시작을 num1로 지정.
2. 끝을 num2+1로 지정.
3. 부분 배열 반환.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 시작을 num1로 지정 |
| 2단계 | 끝을 num2+1로 지정 |
| 3단계 | 부분 배열 반환 |

### 왜 이렇게 풀었는가?

시작을 num1로 지정 → 끝을 num2+1로 지정 → 부분 배열 반환. 문제의 끝 인덱스는 포함하지만 슬라이싱의 stop은 제외한다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 문제의 끝 인덱스는 포함하지만 슬라이싱의 stop은 제외한다.

### 기억할 것

- 슬라이싱 · 인덱스
- 첫 예시 `[1,2,3,4,5], 1, 3`를 손으로 따라가며 `[2,3,4]`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
