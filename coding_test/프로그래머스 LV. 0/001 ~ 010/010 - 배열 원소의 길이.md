# 010. 배열 원소의 길이

## <문제>

> 문자열 배열 strlist의 각 원소 길이를 순서대로 담은 배열을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(strlist)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 문자열 배열 strlist의 각 원소 길이를 순서대로 담은 배열을 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `["We","are","the","world!"]` | `[2,3,3,6]` |
| `["I","Love","Programmers."]` | `[1,4,12]` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(strlist):
    answer = []
    for i in range(len(strlist)):
        answer.append(len(strlist[i]))
    return answer
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(strlist):
    return [len(word) for word in strlist]
```

## <해설>

### 문제 핵심

- 구할 값: 문자열 배열 strlist의 각 원소 길이를 순서대로 담은 배열을 반환하세요.
- 핵심 문법: **len · 리스트 컴프리헨션**
- 주의할 조건: 배열의 길이가 아니라 배열 안의 각 문자열 길이를 구한다. 구두점도 문자 수에 포함한다.

### 풀이 순서

1. 문자열 원소 순회.
2. len으로 길이 계산.
3. 결과 배열에 추가.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 문자열 원소 순회 |
| 2단계 | len으로 길이 계산 |
| 3단계 | 결과 배열에 추가 |

### 왜 이렇게 풀었는가?

문자열 원소 순회 → len으로 길이 계산 → 결과 배열에 추가. 배열의 길이가 아니라 배열 안의 각 문자열 길이를 구한다. 구두점도 문자 수에 포함한다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 배열의 길이가 아니라 배열 안의 각 문자열 길이를 구한다. 구두점도 문자 수에 포함한다.

### 기억할 것

- len · 리스트 컴프리헨션
- 첫 예시 `["We","are","the","world!"]`를 손으로 따라가며 `[2,3,3,6]`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
