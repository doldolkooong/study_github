# 008. 모음 제거

## <문제>

> 문자열 my_string에서 영어 모음 a, e, i, o, u를 제거한 문자열을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(my_string)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 문자열 my_string에서 영어 모음 a, e, i, o, u를 제거한 문자열을 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `"bus"` | `"bs"` |
| `"nice to meet you"` | `"nc t mt y"` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(my_string):
    word = ['a', 'e', 'i', 'o', 'u']
    result = []
    for i in range(len(my_string)):
        if my_string[i] not in word:
            result.append(my_string[i])
    return "".join(result)
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(my_string):
    return "".join(ch for ch in my_string if ch not in "aeiou")
```

## <해설>

### 문제 핵심

- 구할 값: 문자열 my_string에서 영어 모음 a, e, i, o, u를 제거한 문자열을 반환하세요.
- 핵심 문법: **not in · 필터링**
- 주의할 조건: 코드가 제거하는 대상은 소문자 모음이다. 공백과 나머지 문자의 순서를 보존한다.

### 풀이 순서

1. 모음 후보 지정.
2. 모음이 아닌 문자만 저장.
3. join으로 연결.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 모음 후보 지정 |
| 2단계 | 모음이 아닌 문자만 저장 |
| 3단계 | join으로 연결 |

### 왜 이렇게 풀었는가?

모음 후보 지정 → 모음이 아닌 문자만 저장 → join으로 연결. 코드가 제거하는 대상은 소문자 모음이다. 공백과 나머지 문자의 순서를 보존한다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 코드가 제거하는 대상은 소문자 모음이다. 공백과 나머지 문자의 순서를 보존한다.

### 기억할 것

- not in · 필터링
- 첫 예시 `"bus"`를 손으로 따라가며 `"bs"`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
