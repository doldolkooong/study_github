# 009. 숨어있는 숫자의 덧셈(1)

## <문제>

> 문자열 my_string 안의 숫자를 한 자리씩 찾아 그 합을 반환하세요.

### 입력 / 조건

- 함수 선언: `solution(my_string)`
- 제공된 문제 설명과 아래 예시를 기준으로 풀이한다.

### 출력 / 요구사항

- 문자열 my_string 안의 숫자를 한 자리씩 찾아 그 합을 반환하세요.

### 예시

사용자가 제공한 입출력 예시다.

| 입력 | 결과 |
|---|---|
| `"aAb1B2cC34oOp"` | `10` |
| `"1a2b3c4d123"` | `16` |

---

## <코드>

### 내가 작성한 코드

제공한 풀이의 로직을 유지했다. 일부 주석과 빈 줄은 정리했다.

```python
def solution(my_string):
    answer = 0
    for i in range(len(my_string)):
        if my_string[i].isdigit():
            answer += int(my_string[i])
    return answer
```

### 수정한 코드 / 최종 코드

같은 문제를 푸는 간결화 또는 저장 공간 개선 예시다. 기존 코드가 오답이라는 의미는 아니다.

```python
def solution(my_string):
    return sum(int(ch) for ch in my_string if ch.isdigit())
```

## <해설>

### 문제 핵심

- 구할 값: 문자열 my_string 안의 숫자를 한 자리씩 찾아 그 합을 반환하세요.
- 핵심 문법: **isdigit · int · 누적 합**
- 주의할 조건: 34를 34로 더하지 않고 3+4로 더한다. 영문과 ASCII 숫자로 이루어진 문제 입력을 기준으로 한다.

### 풀이 순서

1. 각 문자 확인.
2. 숫자 문자만 int로 변환.
3. 한 자리씩 더함.

### 코드 설명

| 처리 단계 | 의미 |
|---|---|
| 1단계 | 각 문자 확인 |
| 2단계 | 숫자 문자만 int로 변환 |
| 3단계 | 한 자리씩 더함 |

### 왜 이렇게 풀었는가?

각 문자 확인 → 숫자 문자만 int로 변환 → 한 자리씩 더함. 34를 34로 더하지 않고 3+4로 더한다. 영문과 ASCII 숫자로 이루어진 문제 입력을 기준으로 한다.

### 막힌 부분 / 실수

> 실제로 막혔던 경험을 대신 작성한 기록이 아니라, 이 풀이에서 확인할 주의점이다.

- 34를 34로 더하지 않고 3+4로 더한다. 영문과 ASCII 숫자로 이루어진 문제 입력을 기준으로 한다.

### 기억할 것

- isdigit · int · 누적 합
- 첫 예시 `"aAb1B2cC34oOp"`를 손으로 따라가며 `10`가 나오는 이유를 설명한다.
- 반환값의 자료형과 입력의 순서·경계 조건을 다시 확인한다.
