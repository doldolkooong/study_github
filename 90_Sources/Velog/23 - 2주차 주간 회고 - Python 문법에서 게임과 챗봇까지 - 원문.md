**📢 08.10 (월) - 자료형 심화 & 조건문·반복문·예외처리**

가상환경을 만들고 숫자, 문자, 리스트, 튜플, 틱셔너리, 집합, 불리언 등 자료구조를 복습하고 조건문과 반복문, 예외처리까지 진도가 빨리 나간 날이었다.


> - 가상환경 생성 (uv)
- 숫자, 문자열, 리스트, 튜플, 딕셔너리, 집합, 불리언
- 조건문, 반복문 (break/continue/for-else)
- 예외처리 (try/except/else/finally, assert, raise)

익숙한 내용들이 많았지만 학부 때 예외처리는 제대로 짚고 넘어간 적이 없어 조금 낯설었다. 오류가 나도 일단 동작만 하면 된다고 생각했던 예전 습관을 돌아보게 된 날이었다.

**💻 08.11 (화) - 함수**

함수의 형태부터 시작해서 scope, 기본값 파라미터, 가변 파라미터, 키워드 파라미털르 배우고 리스트를 정렬하여 최솟값, 최대값, 중간값 구하기와 가위바위보 게임을 함수로 구현해봤다.

> - 함수 기본 구조 & scope
- 입력변수 기본값, 가변 파라미터, 키워드 가변 파라미터
- 함수 활용 문제 (정렬/최솟값/최댓값/중간값, 가위바위보)
- 특수 함수: 람다, 클로저, 콜백, 재귀, 데코레이터, 이터레이터, 제너레이터

특히 전엔 어렵고 헷갈린다고 느꼈던 람다가 이제는 조금 익숙해진 거 같다. 아직 데코레이터와 이터레이터, 제너레이터는 이해가 잘 되지 않지만 다시 한번 복습을 해봐야겠다. 가위바위보 문제를 풀 때 처음에는 조건 분기에 헷갈리는 부분과 함수로 생성하는 부분이 어려웠지만 몇번 반복하고 나니 가위바위보 만드는 건 익숙해졌다.



수업 내용 정리 - [Day 4 수업 내용 정리](https://velog.io/@doldolkoong/%ED%94%8C%EB%A0%88%EC%9D%B4%EB%8D%B0%EC%9D%B4%ED%84%B0-SK%EB%84%A4%ED%8A%B8%EC%9B%8D%EC%8A%A4-Family-AI-%EC%BA%A0%ED%94%84-36%EA%B8%B0-DAY4-26.08.11)

<br>

**💻 08.12 (수) - 클래스**

가위바위보 문제를 enum으로 다시 풀어보는 것으로 시작하여 클래스, 인스턴스, 상속, 접근지정자, 매직메서드, 싱글톤 패턴, 모듈까지 객체지향의 개념들에 대해 학습하였다.

> - 클래스, 인스턴스, __init__
- 상속, 접근 지정자 (public/private)
- 데코레이터 (@property)
- 매직 메서드
- 디자인 패턴 - 싱글톤
- 모듈

함수의 이해도과 완벽하지 않은 상태해서 객체지향까지 배우다보니, self, __init__, __new__ 같은 새로운 형태의 문법을 이해하는데 시간이 걸렸다. 확실히 학부 때 했던 공부는 겉핥기식이었다는 걸 다시 한번 더 느끼게 됐다.... 간단한 예제를 반복 작성하며 익숙해지는 연습이 필요한 거 같다.


수업 내용 정리 - [Day 5 수업 내용 정리](https://velog.io/@doldolkoong/%ED%94%8C%EB%A0%88%EC%9D%B4%EB%8D%B0%EC%9D%B4%ED%84%B0-SK%EB%84%A4%ED%8A%B8%EC%9B%8D%EC%8A%A4-Family-AI-%EC%BA%A0%ED%94%84-36%EA%B8%B0-DAY5-26.08.12)

<br>

**💻 08.13 (목) - 표준 라이브러리 & streamlit**

기존 가위바위보 게임에서 하나빼기 규칙을 추가하는 문제를 풀고 collections, math, datetime, 정규포현식 등 표준라이브러리를 익힌 뒤 streamlit을 통해 웹 구현을 해보았다.

> - 하나 빼기 게임 구현
- 표준 라이브러리 (collections, math, datetime, 정규표현식 등)
- streamlit (마크다운/헤더, 데이터프레임, 버튼·폼, 멀티페이지)

streamlit으로 코드를 수정하면 화면이 실시간으로 바뀌는 게 신기했다. 다만 가위바위보 문제를 풀면서 사용자 입력에 대한 예외 처리를 충분히 고려하지 못했던 게 아쉬웠고, 다음번엔 잘못된 입력 상황까지 미리 생각하고 짜야겠다는 생각이 들었다.

수업 내용 정리 -[Day 6 수업 내용 정리](https://velog.io/@doldolkoong/%ED%94%8C%EB%A0%88%EC%9D%B4%EB%8D%B0%EC%9D%B4%ED%84%B0-SK%EB%84%A4%ED%8A%B8%EC%9B%8D%EC%8A%A4-Family-AI-%EC%BA%A0%ED%94%84-36%EA%B8%B0-DAY6-2026.08.13)

<br>

**💻 08.14 (금) 게임 구현 & 챗봇 만들기**

묵찌빠 게임 로직을 직접 구현해보고, 강사님께 코드 디자인 하는 방식에 대한 피드백을 받았다. 오후에는 streamlit과 groq api를 활용하여 챗봇을 만들어봤다.

> - 묵찌빠 게임 구현 (공격권 판정 로직)
- 코드 주석 작성 피드백 (주어 통일하기, 코드 작성에 도움이 되도록 쓰기)
- chatbot 구현 (streamlit + groq + python-dotenv)

내가 만든 프로그램이 실제로 채팅에 응답하는 걸 처음 봤을 때 신기하고 재밌었다. 다만 기능을 여러 파일(class, function)로 나누어 모듈화하는 부분은 아직 감이 잘 안 잡혀서, 앞으로 여러 코드를 직접 짜보면서 익혀야겠다. 그리고 나는 왜 하나빼기보다 묵찌빠 구현이 더 쉬운 건지 아직도 모르겠다..........

**👍좋았던 점**

>- 파이썬 기초를 넘어 함수, 클래스, 표준 라이브러리, streamlit까지 배우면서 파이썬의 모든 것을 배울 수 있었다.
- 내가 짠 코드로 가위바위보, 묵찌빠 게임이 실제로 동작하고, 심지어 챗봇까지 만들어 대화가 오가는 걸 보니 배운 걸 바로 눈으로 확인할 수 있어서 재밌었다.
- 강사님께 코드 주석 작성법에 대한 구체적인 피드백을 받으면서, 그냥 코드를 따라 치는 게 아니라 왜 이렇게 짜는지 고민하는 습관을 들일 수 있었다.

<br>

**😂아쉬웠던 점**

>- 분명 지난 주까지는 학습 속도가 조금 느린데... 싶었지만 하루 만에 배우는 개념의 양이 확 늘면서, 함수의 기본기가 완전히 다져지지 않은 상태에서 객체지향 개념까지 배우다 보니 소화하기 벅찬 날들이 있었다.
- 게임 로직을 구현할 때마다 사용자 입력값에 대한 예외 처리를 놓치는 경우가 반복돼서, 코드를 짤 때부터 예외 상황을 먼저 고려하는 습관이 아직 부족하다는 걸 느꼈다.
- 기능을 여러 파일과 함수·클래스로 나누어 모듈화하는 감각이 아직 부족해서, 챗봇을 만들 때도 어떤 역할을 어디에 나눠야 할지 고민을 많이 해봐야겠다.
