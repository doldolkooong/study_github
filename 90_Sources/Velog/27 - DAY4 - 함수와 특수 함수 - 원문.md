**1. 리스트 정렬 & 최솟값·최댓값·중간값 구하기**

예시 리스트 `[8, 6, 2, 8, 5, 1, 2, 5, 4, 9]`에서 최솟값(1), 최댓값(9), 중간값(5)을 구하는 문제.

<br>

- sort 함수 미사용 (버블 정렬 직접 구현)

```python
lst = [8, 6, 2, 8, 5, 1, 2, 5, 4, 9]

temp = []

# 리스트 정렬
for j in range(len(lst)-1):
    for i in range(len(lst)-1):
        if lst[i] > lst[i+1]:
            lst[i], lst[i+1] = lst[i+1], lst[i]
        elif lst[i] < lst[i+1]:
            lst[i], lst[i+1] = lst[i], lst[i+1]

print("정렬된 리스트 : ", lst)
print("최대값 : ", lst[-1])
print("최소값 : ", lst[0])

if len(lst) % 2 == 0:
    print("중간값 : ", ((lst[len(lst)//2-1] + lst[len(lst)//2])/2))
else:
    print("중간값 : ", lst[len(lst)//2])

> 정렬된 리스트 :  [1, 2, 2, 4, 5, 5, 6, 8, 8, 9]
> 최대값 :  9
> 최소값 :  1
> 중간값 :  5.0
```

**2. 함수**

함수 : 자주 사용하는 코드를 하나의 이름으로 묶어놓은 것.

```python
def 함수명(입력변수):
    수행할 프로그램1
    수행할 프로그램2
    return 출력변수
```

함수는 입력변수·출력변수 유무에 따라 4가지 형태로 나뉜다.

```python
# 1) 입력변수 X, 출력변수 X
def func1():
    print("Hello World")

func1()
> Hello World
```

```python
# 2) 입력변수 O, 출력변수 X
def func2(param1):
    print(f"{param1}님, 안녕하세요.")

func2("안뇽")
> 안뇽님, 안녕하세요.
```

```python
# 3) 입력변수 X, 출력변수 O
def func3():
    param1 = "홍길동"
    return f"{param1}님, 안녕하세요."

func3()
> '홍길동님, 안녕하세요.'
```

```python
# 4) 입력변수 O, 출력변수 O
def func4(param1):
    return f"{param1}님, 안녕하세요."

func4("바보")
> '바보님, 안녕하세요.'
```

**3. scope()**

변수를 어디까지 사용할 수 있는지에 대한 범위. 함수 안에서 선언한 변수는 함수 안에서만 사용 가능하다.

```python
x = 10

def func5():
    y = 20
    print(f"함수 안에서 선언한 변수의 값: {y}")

func5()
> 함수 안에서 선언한 변수의 값: 20
```

함수 밖에서 선언한 변수를 함수 안에서 쓰려면, 입력변수로 넘겨주는 방식이 안전하다.

```python
def func6(p_x):
    y = 20 + p_x
    return f"함수 안에서 선언한 변수의 값 : {y}"

func6(x)
```

**4. 입력변수**

기본값(default)을 지정하면 값을 입력하지 않아도 실행되고, 입력하면 입력값이 우선 적용된다.

```python
def func(p_x=0):
    return p_x + 10

func()      # 10
func(20)    # 30
```

```python
def func(p_x=0, p_y=0):
    return p_x + 10 + p_y

func(20, 28)   # 58
func(20)       # 30
func(p_y=20)   # 30
```

⚠️ 기본값이 없는 파라미터는 기본값이 있는 파라미터보다 앞에 와야 한다.

```python
def func(p_x=0, p_y):   # SyntaxError
    return p_x + 10 + p_y
```

```python
def func(p_y, p_x=0):   # 순서를 바꾸면 오류 발생 안 함
    return p_x + 10 + p_y

func(p_y=20)   # 30
func(20, 10)   # 40
```

> 기본값 없음 = 필수 입력, 기본값 있음 = 선택 입력. 보통 필수 파라미터를 먼저 작성한다.

**5. 가변 파라미터**

실제 데이터의 개수를 알 수 없을 때 `*파라미터명` 형태로 사용한다.

```python
def add(*p_x):   # 가변 파라미터 (튜플로 전달됨)
    add_sum = 0
    for i in p_x:
        add_sum += i
    return add_sum

add(1, 2)   # 3
```

**6. 키워드 가변 파라미터**

`*args`는 튜플, `**kwargs`는 딕셔너리로 전달된다는 차이가 있다. 튜플은 인덱스로 식별하지만 딕셔너리는 키로 값을 식별할 수 있다는 장점이 있다.

```python
def info(**kwargs):
    print(type(kwargs))
    print(f"{kwargs['p_name']}님은 나이가 {kwargs['p_age']}입니다.")

info(p_name="홍길동", p_age=33)
> <class 'dict'>
> 홍길동님은 나이가 33입니다.
```

```python
def info(**kwargs):
    name = "바보"
    age = 19

    if 'p_name' in kwargs:
        name = kwargs['p_name']
    if 'p_age' in kwargs:
        age = kwargs['p_age']

    print(f"{name}님은 나이가 {age}입니다.")

info()
> 바보님은 나이가 19입니다.
```

**7. 함수 활용 문제**

- 문제 1: 리스트 정렬 / 최솟값 / 최댓값 / 중간값을 각각 함수로 구현

```python
import random

lst = [random.randint(0,9) for i in range(random.randint(10,30))]

def lst_sort():
    lst.sort()
    return lst

def lst_min():
    return lst[0]

def lst_max():
    return lst[-1]

def lst_med():
    if len(lst) % 2 == 0:
        return (lst[len(lst)//2-1] + lst[len(lst)//2]) / 2
    return lst[len(lst)//2]

print("정렬된 리스트 : ", lst_sort())
print("최소값 : ", lst_min())
print("최대값 : ", lst_max())
print("중간값 : ", lst_med())
```

더 간결하게 줄이면 아래처럼도 가능하다.

```python
import random

lst = [random.randint(0,9) for _ in range(random.randint(5,9))]

def get_med(p_lst):
    if len(p_lst) % 2 != 0:
        return p_lst[len(p_lst)//2]
    return (p_lst[len(p_lst)//2-1] + p_lst[len(p_lst)//2]) / 2

def func(p_lst):
    return f"{p_lst[0]} / {p_lst[-1]} / {get_med(p_lst)}"

func(lst)
```

- 문제 2: 가위바위보 게임 구현

`random`으로 컴퓨터 선택을 만들고, 승리 규칙을 딕셔너리로 정의해 이기는 경우/비기는 경우/지는 경우를 판별하고 횟수를 카운트했다.


```python
import random

choices = ["가위", "바위", "보"]

win = {
    "가위": "보",
    "바위": "가위",
    "보": "바위"
}

count = 0
computer_win = 0
user_win = 0

def main_game(user_choice, computer_choice):
    global computer_win, user_win

    if win[user_choice] == computer_choice:
        print("이겼습니다!")
        user_win += 1
    elif user_choice == computer_choice:
        print("비겼습니다!")
    else:
        print("졌습니다!")
        computer_win += 1

while True:
    print("가위 바위 보 시작")
    user_choice = input("가위, 바위, 보 중 하나 골라주세요!").strip()
    computer_choice = random.choice(choices)
    count += 1

    if user_choice not in choices:
        print("가위, 바위, 보 중 하나 골라주세요 ㅡㅡ")
        continue

    print(f"user의 선택 : {user_choice}")
    print(f"computer의 선택 : {computer_choice}")

    main_game(user_choice, computer_choice)
    print(f"사용자 승리 횟수 : {user_win}, 컴퓨터 승리 횟수: {computer_win}")
```
나는 이렇게 풀었는데, 강사님은 enum을 활용하여 코드를 짧게 작성하셨다.

**8. 특수 함수**

1) 람다 함수 : 함수를 한 줄로 표현

```python
def add(num1, num2):
    return num1 + num2
add(3, 5)   # 8

add_lambda = lambda num1, num2: num1 + num2
add_lambda(3, 5)   # 8
```

<br>

2) 클로저 : 함수 안에 함수를 선언하고, 내부 함수를 반환해서 나중에 실행

```python
def func_out(out_param):
    a = 10
    def func_in(qwer):
        return a + out_param + qwer
    return func_in

func_out(5)(3)   # 18
```

<br>

3) 콜백 함수 : 함수를 입력변수로 받아 실행하는 함수

```python
def add_one(num):
    return num + 1

def add_three(num):
    return num + 3

def call_func(param: int, func1, func2):
    if param % 2 == 0:
        return func1(param)
    return func2(param)

call_func(4, add_one, add_three)   # 5
```

<br>

4) 재귀 함수 : 자기 자신을 호출하는 함수

```python
def add_one(num):
    if num < 10:
        num = add_one(num * 2)
    return num + 1

add_one(1)   # 21
```

<br>

5) 데코레이터 : 콜백 함수 + 클로저를 조합해 기존 함수 실행 전후에 동작을 추가

```python
def decorator_func(org_func):
    def wrapper_func():
        print("org_func가 실행되기 전입니다.")
        org_func()
    return wrapper_func

@decorator_func
def do_func():
    print("original 함수가 실행 되었습니다.")

do_func()
> org_func가 실행되기 전입니다.
> original 함수가 실행 되었습니다.
```
