## [플레이데이터 SK네트웍스 Family AI 캠프 36기] 1주차 주간회고 (26.08.05 ~ 26.08.07)



![](https://velog.velcdn.com/images/doldolkoong/post/f9c05bca-b3e3-41bb-aa13-8c08e58fb691/image.png)


부트캠프 첫 주가 지나갔다. OT부터 개발 환경 세팅, Git과 Python 가상환경, python 변수 및 상수 실습을 진행한 3일이었지만, 그만큼 배운 것도 많고 느낀 것도 많았던 한 주였다.


**회고 순서**
>1. 08.05 (수) - OT
2. 08.06 (목) - 개발 환경 세팅

#### **📢 08.05 (수) - Orientation**

부트캠프 오리엔테이션으로 시작했다. 2시부터 5시까지 진행 되었다. 강의실에 모여 앞으로 6개월간 함께할 SK네트웍스 Family AI 캠프 36기 과정에 대한 전반적인 안내를 받았다.

>교육 일정: 2026년 8월 6일 ~ 2027년 1월 29일 (총 120일), 주중 09:00~18:00 (1일 8시간, 총 960시간)
커리큘럼 구성: 프로그래밍과 데이터 기초 → 데이터 분석과 머신러닝/딥러닝 → LLM(초거대언어모델) → AI 활용 애플리케이션 개발 → 최종 프로젝트


각 교과마다 단위 프로젝트와 성취도 평가가 포함되어 있다.(이 점이 너무 좋았다)

- 팀 프로젝트: 팀은 전공, 성실도, 기술 이해도 등을 고려해 강사님과 매니저님이 편성하며, 최종 프로젝트는 현직자 멘토와 20시간 멘토링이 함께 진행된다고 한다.

- 출결 관리: 고용24 직업훈련 출결관리 앱을 설치하고 기기 등록을 완료해야 출결이 인정되며, 비콘(Beacon) 인식 방식으로 출결체크가 이루어진다.(참고로 이상이 있으면 매니저님께 말씀드리면 된다)

- 지각·조퇴·외출이 3회 누적되면 결석 1회로 처리된다는 점이 인상 깊었다(그만큼 관리가 철저하다는 뜻이기도 하고).

- 훈련장려금 & 마일리지: 단위기간 출석률 80% 이상 시 훈련장려금이 지급되고, 별도로 스터디 인증·자격증 취득·블로그 회고 등을 통해 마일리지(최대 40만원)까지 챙길 수 있는 구조였다.


- 생활 안내: 교육센터는 평일 08:30~21:50 운영, 노트북 대여 가능

- 기본훈련: 소방훈련(분말소화기 사용법)과 부정훈련 예방 교육을 진행했고, 개인정보 수집·이용 동의서, 입과 서약서, 제적경고 서약서를 작성했다.


- ICE Breaking: 자기소개(Self PR)를 하고, 5~6명씩 팀을 이뤄 AI 이미지 생성 툴로 "우리 반을 대표하는 AI 마스코트"를 만드는 활동을 했다. 넞을 많이 가려 말을 잘 못했지만 재밌었다.


#### **💻 08.06 (목) - 개발 환경 세팅**

본격적인 수업 첫날. 오늘 하루는 온전히 개발 환경을 세팅하는 데 사용했다.

>- Git 설치 및 사용자 정보 설정
- 기존에 설치되어 있던 Python, Anaconda를 모두 삭제하고 Python 3.13.15를 새로 설치 (설치 시 PATH 체크는 필수!)
- VS Code 설치 및 Python, Git Graph 확장 프로그램 설치
- C:\dev 아래 course / study / project 폴더 구조로 개발자 폴더 생성
- VS Code에서 Ctrl+Shift+P → Git: Clone으로 강의자료 저장소 클론
- PowerShell 실행 정책을 RemoteSigned로 변경
- 빠른 패키지·버전 관리를 위한 uv 설치
- WSL(Ubuntu)과 Docker Desktop까지 설치




하루 종일 설치만 했지만, 각 도구를 왜 쓰는지 이해하면서 진행하려고 했던 게 오히려 더 오래 기억에 남는 하루였다.

**👍 좋았던 점**
>- 다른 직종을 퇴사한 후 3주 정도 쉬면서 '이렇게 지내도 괜찮을까?' 하는 불안감이 있었다. 다행히 교육 과정에 합격하여 다시 회사처럼 규칙적인 생활을 시작하게 되었고, 무엇보다 이것이 '일'이 아닌 '공부'라는 점이 생각보다 크게 다가왔다. 학부 때 배운 것이 부족하다 생각하여 늘 공부를 하고 싶었는데 배울 수 있는 기회가 생겨서 좋았다.

>- 새로운 사람들을 만날 수 있다는 점도 좋았다. ICE Breaking 때 어색하게 시작했지만, 같이 6개월을 보낼 동기들이라고 생각하니 벌써 기대가 된다.
평소에 관심 있던 AI/데이터 분야를 제대로 공부할 수 있게 됐다는 것 자체가 가장 큰 동기부여가 된다.


**😂 아쉬웠던 점**
>- 1호선 배차간격이 생각보다 너무 길어서 통학길이 조금 힘들었다... (2일 연속 내내 57분에 도착했다... 1시간 거리여서 1시간 30분 일찍 나왔는데도 말이다... 다음 주에는 좀 더 빨리 나와야겠다.)

>- 개발 환경 프로그램 셋팅하는 데 생각보다 시간이 오래 걸렸다. Git, Python, VS Code, uv, WSL, Docker까지 한 번에 설치하다 보니 예상보다 하루를 꽉 채워 썼는데, 다음번엔 미리 설치 순서를 파악해두면 더 효율적으로 진행할 수 있을 것 같다.

>- 낯을 많이 가리는 성격이라 먼저 다가가 대화를 시작하는 것이 쉽지 않았다. 다행히 먼저 다가와 말을 걸어주신 분들이 있어서 조금 더 편하게 적응할 수 있었고, 감사한 마음이 들었다. 앞으로는 조금 더 적극적으로 먼저 다가가 보려고 한다.(긴장한 나머지 잠을 많이 못 잔 것도 문제..)
