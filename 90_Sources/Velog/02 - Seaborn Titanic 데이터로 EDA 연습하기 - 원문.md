# 🚢 Seaborn Titanic 데이터로 EDA 연습하기

## Pandas를 활용한 데이터 탐색부터 변수 간 관계 분석까지

이번에는 `seaborn` 라이브러리에서 제공하는 Titanic 데이터셋을 이용하여 EDA(Exploratory Data Analysis, 탐색적 데이터 분석)를 진행해보았다.

단순히 `groupby()`나 `mean()` 같은 Pandas 문법을 사용하는 것에서 끝내지 않고, 분석 과정에서 다음 질문에 답하는 것을 목표로 했다.

1. 전체 승객의 생존률은 어느 정도인가?
2. 성별에 따라 생존률 차이가 있는가?
3. 객실 등급에 따라 생존률이 달라지는가?
4. 연령대와 생존 여부는 어떤 관계가 있는가?
5. 혼자 탑승한 사람과 가족 동반 승객의 생존률은 다른가?
6. 승선 지역에 따라 생존률 차이가 있는가?
7. 높은 운임을 지불한 승객이 실제로 더 많이 생존했는가?
8. 어떤 변수가 생존 여부와 가장 큰 관련성을 보이는가?

특히 이번 분석에서는 단순히 **"A가 높으면 B도 높다"**라고 결론 내리는 것이 아니라, 다른 변수를 함께 살펴보면서 처음 세운 가설이 실제로도 타당한지 확인하는 데 중점을 두었다.

## 1. 데이터 불러오기

```python
import seaborn as sns

df = sns.load_dataset('titanic')

df.head()
```

`seaborn`의 `load_dataset()`을 사용하면 별도의 CSV 파일을 다운로드하지 않고도 실습용 데이터셋을 바로 불러올 수 있다.

Titanic 데이터의 주요 컬럼은 다음과 같다.

| 컬럼            | 설명                                 |
| ------------- | ---------------------------------- |
| `survived`    | 생존 여부, 0 = 사망 / 1 = 생존             |
| `pclass`      | 객실 등급, 1 = 1등석 / 2 = 2등석 / 3 = 3등석 |
| `sex`         | 성별                                 |
| `age`         | 나이                                 |
| `sibsp`       | 함께 탑승한 형제·자매·배우자 수                 |
| `parch`       | 함께 탑승한 부모·자녀 수                     |
| `fare`        | 운임                                 |
| `embarked`    | 승선 항구 코드                           |
| `class`       | 객실 등급 문자열                          |
| `who`         | man / woman / child                |
| `adult_male`  | 성인 남성 여부                           |
| `deck`        | 객실 Deck                            |
| `embark_town` | 승선 지역                              |
| `alive`       | 생존 여부 문자열                          |
| `alone`       | 혼자 탑승했는지 여부                        |

## 6. Boolean Indexing을 이용한 조건 필터링

EDA에서는 전체 데이터를 보는 것뿐 아니라 특정 조건에 해당하는 데이터만 추출하는 작업도 자주 사용한다.

### 여성 승객 조회

```python
df[df['sex'] == 'female']
```

`df['sex'] == 'female'`의 결과는 각 행에 대해 `True / False`를 반환한다.

그리고 이를 DataFrame의 인덱싱 조건으로 사용하면 `True`인 행만 추출된다.

### 1등석 승객 조회

```python
df[df['pclass'] == 1]
```

### 여성인 동시에 1등석인 승객

두 조건을 동시에 만족시키려면 `&`를 사용한다.

```python
cond1 = df['sex'] == 'female'
cond2 = df['pclass'] == 1

df[cond1 & cond2]
```

Pandas에서 조건을 여러 개 사용할 때는 다음 연산자를 사용할 수 있다.

```text
&  → AND
|  → OR
~  → NOT
```

### 30세 이상 승객 수

```python
len(df[df['age'] >= 30])
```

결과:

```text
330
```

또는 Boolean의 `True`가 계산 과정에서 1처럼 처리된다는 특징을 이용해 다음과 같이 작성할 수도 있다.

```python
(df['age'] >= 30).sum()
```

### 20대 승객 조회

```python
cond1 = df['age'] >= 20
cond2 = df['age'] < 30

df[cond1 & cond2]
```

20대는 `20 이상 30 미만`으로 조건을 설정했다.

### 운임이 100 이상인 승객

```python
len(df[df['fare'] >= 100])
```

결과:

```text
53
```

### Southampton에서 승선한 승객

```python
df[df['embark_town'] == 'Southampton']
```

이처럼 Boolean Indexing을 이용하면 원하는 조건에 해당하는 데이터를 쉽게 추출할 수 있다.


즉,

* 3등석: 약 **24.2%**

Titanic 데이터에서 `pclass`는 숫자가 작을수록 높은 등급이다.

```text

2 → 2등석
3 → 3등석
```

따라서 **상위 객실 등급에 탑승한 승객일수록 생존률이 높게 나타났다.**

## 11. 객실 등급별 평균 운임

```python
df.groupby('pclass')['fare'].mean()
```

결과:

```text
1    84.15
2    20.66
3    13.68
```

1등석 평균 운임이 압도적으로 높다.

이 결과는 이후 `fare`와 생존률의 관계를 분석할 때 매우 중요한 단서가 된다.

왜냐하면,

```text
높은 fare
    ↓
1등석 승객일 가능성이 높음
    ↓
1등석의 생존률도 높음
```

이라는 관계가 존재할 수 있기 때문이다.

즉 `fare`가 높아서 생존률이 높은 것인지, 높은 운임과 연결된 `pclass` 때문인지 추가 분석이 필요하다.

### 여성

* 2등석: 약 92.1%
* 3등석: 50.0%

### 남성

## 15. 파생변수 만들기 - 연령대

`age`는 연속형 데이터이기 때문에 그대로 분석하는 것보다 일정 구간으로 나누면 연령대별 특성을 확인하기 쉽다.

다음과 같이 연령대를 구분했다.

```text
0 ~ 9      → 10대 미만
10 ~ 19    → 10대
20 ~ 29    → 20대
30 ~ 39    → 30대
40 ~ 49    → 40대
50 ~ 59    → 50대
60 이상    → 60대 이상
```

### 결측치에 주의하기

`age`에는 결측치가 존재한다.

따라서 단순히 마지막 `else`에서 `60대 이상`을 반환하면 `NaN`도 60대 이상으로 분류될 수 있다.

이를 방지하기 위해 결측치를 먼저 처리하였다.

```python
import pandas as pd

def age_classify(age):
    if pd.isna(age):
        return None
    elif 0 <= age < 10:
        return '10대 미만'
    elif 10 <= age < 20:
        return '10대'
    elif 20 <= age < 30:
        return '20대'
    elif 30 <= age < 40:
        return '30대'
    elif 40 <= age < 50:
        return '40대'
    elif 50 <= age < 60:
        return '50대'
    else:
        return '60대 이상'

df['age_group'] = df['age'].apply(age_classify)
```

`apply()`를 사용하면 각 `age` 값에 직접 만든 함수를 적용할 수 있다.

## 16. 연령대별 생존률

```python
df.groupby('age_group')['survived'].mean()
```

결과:

```text
10대 미만    0.612903
10대        0.401961
20대        0.350000
30대        0.437126
40대        0.382022
50대        0.416667
60대 이상    0.290640
```

가장 높은 생존률을 보인 연령대는 **10대 미만으로 약 61.3%**였다.

반대로 60대 이상은 약 29.1%로 가장 낮았다.

하지만 여기서 주의할 점이 있다.

```text
20대 → 35.0%
30대 → 43.7%

40대 → 38.2%
50대 → 41.7%
```

처럼 연령이 증가할수록 생존률이 일정하게 감소하지는 않는다.

따라서,

> **"나이가 많을수록 생존률이 낮다"**

라고 단순하게 결론 내리기보다는,

> **"10대 미만 승객의 생존률이 상대적으로 높았다는 특징이 두드러졌다."**

라고 해석하는 것이 더 적절하다.

## 17. 가족 규모 파생변수 생성

Titanic 데이터에는 가족 관계를 나타내는 두 컬럼이 있다.

```text
sibsp → 함께 탑승한 형제·자매·배우자 수
parch → 함께 탑승한 부모·자녀 수
```

이를 이용해 실제 함께 탑승한 가족 규모를 만들었다.

```python
df['family_size'] = df['sibsp'] + df['parch'] + 1
```

마지막 `+1`은 승객 자기 자신을 의미한다.

예를 들어,

```text
sibsp = 1
parch = 2
```

라면

```text
family_size = 1 + 2 + 1 = 4
```

가 된다.

```python
def boarding_classify(family_size):
    if family_size == 1:
        return 'Alone'
    else:
        return 'Family'

df['boarding_type'] = df['family_size'].apply(boarding_classify)
```

## 22. 운임 구간 파생변수

운임을 다음 네 구간으로 나누었다.

```text
1 → 0 이상 20 미만
2 → 20 이상 50 미만
3 → 50 이상 100 미만
4 → 100 이상
```

```python
def fare_classify(fare):
    if 0 <= fare < 20:
        return 1
    elif 20 <= fare < 50:
        return 2
    elif 50 <= fare < 100:
        return 3
    else:
        return 4

df['fare_type'] = df['fare'].apply(fare_classify)
```

---

## 23. 운임 구간별 생존률

```python
df.groupby('fare_type')['survived'].mean()
```

결과:

```text
1    0.277670
2    0.418605
3    0.648148
4    0.735849
```

운임이 높아질수록 생존률도 높아지는 매우 뚜렷한 패턴이 나타난다.

| 운임 구간    |   생존률 |
| -------- | ----: |
| 0 ~ 20   | 27.8% |
| 20 ~ 50  | 41.9% |
| 50 ~ 100 | 64.8% |
| 100 이상   | 73.6% |

처음 이 결과만 봤을 때는 높은 운임 자체가 생존에 긍정적인 영향을 줬다고 생각했다.

하지만 앞서 객실 등급별 평균 운임을 확인했을 때,

```text
1등석 → 평균 84.15
2등석 → 평균 20.66
3등석 → 평균 13.68
```

로 운임과 객실 등급이 강하게 연결되어 있었다.

그래서 `pclass`를 함께 넣어 다시 분석했다.

```python
df.groupby(['pclass', 'fare_type'])['survived'].mean()
```

그 결과 동일한 객실 등급 안에서는 **운임이 증가할수록 생존률이 항상 증가하는 일관된 패턴이 나타나지 않았다.**

### 여기서 얻은 중요한 인사이트

처음에는

```text
fare 증가
→ 생존률 증가
```

처럼 보였다.

하지만 실제로는,

```text
fare가 높은 승객
        ↓
상위 객실 등급일 가능성이 높음
        ↓
상위 객실 등급의 생존률이 높음
```

이라는 구조일 가능성이 있다.

따라서 운임 자체가 생존 확률을 높였다고 단정할 수 없다.

이는 데이터 분석에서 **상관관계와 인과관계를 구분해야 하는 이유**를 잘 보여주는 사례였다.

## 24. Pivot Table 활용

여러 그룹의 값을 동시에 비교하기 위해 `pivot_table()`도 사용했다.

기본 구조는 다음과 같다.

```python
pd.pivot_table(
    df,
    index='행 기준',
    columns='열 기준',
    values='계산할 값',
    aggfunc='집계 방법'
)
```

쉽게 기억하면,

```text
index   → 세로
columns → 가로
values  → 계산 대상
aggfunc → 계산 방법
```

이다.

```python
    '생존': df[df['survived'] == 1]
```

```python
sex_survived = pd.crosstab(
```

### `crosstab()`과 `pivot_table()`의 차이

* `crosstab()` : 두 범주형 변수의 **빈도 비교**에 편리
* `pivot_table()` : 행과 열을 정하고 **평균, 합계, 개수 등의 통계값**을 계산할 때 유용

## 29. Spearman 상관계수 분석

수치형 변수들과 생존 여부 사이의 관계를 확인하기 위해 Spearman 상관계수를 계산했다.

```python
spearman_corr = df.corr(
    method='spearman',
    numeric_only=True
)

print(
    spearman_corr['survived']
    .sort_values(ascending=False)
)
```

주요 결과는 다음과 같았다.

```text
fare           +0.324
family_size    +0.165
age            -0.053
alone          -0.203
pclass         -0.340
adult_male     -0.557
```

Spearman 상관계수는 일반적으로 다음과 같이 해석할 수 있다.

```text
+ 값 → 한 변수가 증가할 때 다른 변수도 증가하는 경향
- 값 → 한 변수가 증가할 때 다른 변수는 감소하는 경향
0에 가까움 → 단조 관계가 약함
```

---

### `pclass`의 음의 상관관계

`pclass`와 `survived`의 상관계수는 약 `-0.34`였다.

여기서 주의해야 할 점은 `pclass` 숫자의 의미이다.

```text
1 = 1등석
2 = 2등석
3 = 3등석
```

따라서 `pclass` 값이 증가한다는 것은 실제 객실 등급이 낮아진다는 뜻이다.

즉,

> `pclass` 값이 증가할수록 생존률은 감소하는 경향이 있었다.

라고 해석할 수 있다.

---

### `fare`의 양의 상관관계

`fare`는 약 `+0.32`의 상관관계를 보였다.

즉 높은 운임과 높은 생존률 사이에는 어느 정도 양의 관계가 존재한다.

하지만 앞서 확인한 것처럼 `fare`는 `pclass`와 연결되어 있기 때문에 운임 자체의 영향이라고 단정하지 않았다.

---

### `sex`가 상관계수 표에 없는 이유

`numeric_only=True`를 사용했기 때문에 문자열 컬럼인 `sex`는 상관계수 계산에서 제외된다.

따라서,

> 상관계수 표에서 가장 높은 변수 = 전체 데이터에서 가장 중요한 변수

라고 바로 결론 내리면 안 된다.

성별은 별도로 확인해야 한다.

```python
df.groupby('sex')['survived'].mean()
```

그 결과 여성 74.2%, 남성 18.9%로 매우 큰 차이를 보였다.

따라서 이번 EDA에서는 생존 여부와 강한 관련성을 가진 변수로

* `sex`
* `pclass`
* `fare`

를 우선적으로 확인하였다.

다만 `fare`는 `pclass`와 관련되어 있기 때문에 두 변수를 독립적으로 해석하지 않았다.

## 30. 1등석은 정말 생존에 유리했을까?

객실 등급별 생존률을 다시 확인했다.

로 나타났다.

### 결론

> 성별과 객실 등급은 모두 생존 여부와 관련이 있으며, 특히 성별의 차이가 매우 크게 나타났다.

|     1 | 어린이 |   5 | 80.0% |
|     2 | 성인  | 154 | 41.6% |
|     2 | 어린이 |  19 |  100% |
|     3 | 성인  | 301 | 20.9% |
|     3 | 어린이 |  54 | 40.7% |

어린이의 생존률은 전체적으로 성인보다 높다.

그러나 3등석 어린이의 생존률은 약 40.7%로 1·2등석 어린이보다 낮았다.

따라서,

> **어린이라는 조건만으로 생존 가능성이 항상 높았다고 볼 수 없으며 객실 등급 역시 관련이 있었다.**

또한 2등석 어린이의 생존률이 100%라고 해서

> "2등석이 어린이에게 가장 안전했다."

라고 바로 결론 내려서는 안 된다.

해당 집단은 19명으로 표본 수가 상대적으로 적기 때문이다.

### EDA에서 평균과 함께 `count`도 확인해야 하는 이유

```text
3명 중 3명 생존 → 100%
100명 중 100명 생존 → 100%
```

둘 다 생존률은 100%이지만 결과의 안정성을 동일하게 볼 수는 없다.

따라서 그룹별 비율을 분석할 때는 가능한 경우 **표본 수와 평균을 함께 확인하는 습관**이 필요하다.

## 35. 최종 분석 결과

### 전체 생존률

전체 승객 891명 중,

* 생존자: 342명
* 사망자: 549명
* 전체 생존률: 약 **38.4%**

였다.

---

### 성별

```text
여성 → 74.2%
남성 → 18.9%
```

성별에 따라 약 55%p 이상의 큰 차이가 나타났다.

이번 분석에서 가장 뚜렷하게 확인된 패턴 중 하나였다.

---

### 객실 등급

```text
1등석 → 63.0%
2등석 → 47.3%
3등석 → 24.2%
```

상위 객실 등급일수록 생존률이 높았다.

---

### 연령대

```text
10대 미만 → 61.3%
10대      → 40.2%
20대      → 35.0%
30대      → 43.7%
40대      → 38.2%
50대      → 41.7%
60대 이상  → 29.1%
```

10대 미만 승객의 생존률이 가장 높았다.

하지만 나이가 증가할수록 생존률이 일정하게 감소하는 형태는 아니었다.

---

### 가족 동반 여부

```text
혼자 탑승 → 30.4%
가족 동반 → 50.6%
```

가족과 함께 탑승한 승객의 생존률이 높았다.

다만 가족 규모별로 나누어 보면 2~4명의 소규모 가족에서 생존률이 높았고, 5명 이상의 가족에서는 다시 낮아졌다.

---

### 운임

사망자와 생존자의 평균 운임은 다음과 같았다.

```text
사망자 → 22.12
생존자 → 48.40
```

운임 구간을 기준으로 보더라도 높은 운임 구간의 생존률이 높았다.

하지만 `pclass`를 함께 고려했을 때 동일 객실 등급 내에서 운임과 생존률의 관계는 일관되지 않았다.

따라서 **운임 자체보다는 객실 등급과 함께 해석하는 것이 적절하다.**

## 36. 최종 결론

분석 결과 Titanic에서는 다음과 같은 특징을 가진 승객들의 생존률이 상대적으로 높게 나타났다.

* **성별:** 여성
* **객실 등급:** 1등석
* **연령대:** 10대 미만
* **가족 동반 여부:** 혼자보다는 가족과 함께 탑승
* **가족 규모:** 특히 2~4명 정도의 소규모 가족
* **운임:** 상대적으로 높은 운임을 지불한 승객

특히 성별에 따른 생존률 차이가 매우 크게 나타났으며, 객실 등급 역시 생존 여부와 뚜렷한 관련성을 보였다.

연령대별로는 10대 미만 승객의 생존률이 가장 높았지만 연령이 증가할수록 생존률이 일정하게 감소하지는 않았다.

가족과 함께 탑승한 승객은 혼자 탑승한 승객보다 높은 생존률을 보였지만, 가족 규모가 너무 클 경우 생존률이 다시 낮아졌다.

운임의 경우 높은 운임을 지불한 승객의 생존률이 높았지만, 운임과 객실 등급이 서로 밀접하게 연결되어 있었다. 따라서 **높은 운임 자체가 생존 확률을 높였다고 단정할 수는 없다.**

종합하면 Titanic 승객의 생존 여부와 가장 뚜렷한 관련성을 보인 변수는 **성별(`sex`)과 객실 등급(`pclass`)**이었으며, 연령, 가족 규모, 운임 등의 변수도 함께 고려할 필요가 있었다.

## 37. 이번 EDA에서 배운 점

이번 Titanic 분석에서 단순한 Pandas 문법보다 더 중요하게 느낀 부분은 **분석 결과를 어떻게 해석하느냐**였다.

처음에는 다음과 같이 단순하게 생각할 수 있었다.

```text
fare가 높다
→ 생존률이 높다
→ 돈을 많이 낸 사람이 더 잘 살아남았다.
```

하지만 객실 등급을 추가해 분석해보니 운임과 객실 등급이 강하게 연결되어 있었고 동일한 객실 등급 내에서는 운임 증가와 생존률 사이에 일관된 패턴이 나타나지 않았다.

즉 하나의 변수만 보고 결론을 내리기보다 다른 변수와의 관계까지 함께 확인해야 했다.

또한 가족 규모 분석에서는 단순 평균만 보는 것이 아니라 `count`를 함께 확인하면서 표본 수의 중요성도 알 수 있었다.

이번 분석을 통해 다음과 같은 EDA의 기본 흐름을 연습할 수 있었다.

```text
데이터 구조 확인
        ↓
결측치 확인
        ↓
Target 분포 확인
        ↓
조건 필터링
        ↓
GroupBy를 이용한 그룹 비교
        ↓
파생변수 생성
        ↓
Pivot Table을 이용한 다변량 비교
        ↓
상관관계 분석
        ↓
추가 변수를 이용한 가설 재검증
        ↓
최종 인사이트 도출
```

단순히 코드를 실행하는 것보다,

> **"왜 이런 결과가 나왔을까?"**

라는 질문을 계속 만드는 것이 EDA에서 중요하다는 것을 확인할 수 있었다.

## 38. 다음 단계 - 머신러닝으로 연결하기

이번 EDA에서는 `survived`와 관련이 있을 것으로 보이는 변수들을 확인했다.

다음 단계에서는 이를 바탕으로 `survived`를 예측하는 분류 모델을 만들어볼 수 있다.

사용할 수 있는 Feature 후보는 다음과 같다.

```text
pclass
sex
age
sibsp
parch
fare
embarked
alone
family_size
age_group
```

전체 과정은 다음과 같이 진행할 수 있다.

```text
1. Feature 선택
2. 결측치 처리
3. 범주형 데이터 인코딩
4. X / y 분리
5. train / validation 분리
6. Baseline 모델 생성
7. 모델 평가
8. 여러 모델 비교
9. Feature Importance 확인
10. EDA 결과와 모델 결과 비교
```

### 머신러닝 단계에서 주의할 컬럼

Titanic 데이터의 `alive`는 사실상 `survived`를 `yes / no`로 표현한 컬럼이다.

따라서 `survived`를 예측하는 모델에서 `alive`를 Feature로 사용하면 정답 정보를 모델에게 미리 제공하는 **Data Leakage**가 발생한다.

또한 다음과 같이 서로 거의 같은 정보를 표현하는 변수들도 있다.

```text
pclass ↔ class
embarked ↔ embark_town
survived ↔ alive
```

따라서 머신러닝에서는 EDA에서 사용한 모든 컬럼을 그대로 넣기보다 **중복 정보와 Target Leakage를 확인한 뒤 Feature를 선택하는 과정**이 필요하다.

다음 분석에서는 EDA에서 확인한 `sex`, `pclass`, `age`, `family_size`, `fare` 등의 변수가 실제 머신러닝 모델에서도 중요한 Feature로 나타나는지 비교해볼 예정이다.
