**4. 리스트**
문자·숫자는 하나의 데이터만 저장, 리스트는 여러 개의 데이터를 저장([ ])한다.

```python
a = ["Hello", "world", "Hi", 2, 3, 0.2]
len(a)
> 6
```
```python
a[0]
> 'Hello'
```
```python
a[-2]
> 3
```

<리스트 연산>
```python
a = [1, 2]
b = [3, 4]

a + b
> [1, 2, 3, 4]
```
```python
a * 3

```
```python
a[0] = 5   # 리스트는 수정 가능
```

- append vs extend
  
```python
a = [1, 2, 3, 4, 5]
b = [6, 7, 8, 9, 10]

```
```python
a.extend(b)   # b의 요소 하나하나를 꺼내서 추가
```

**5. 튜플**
리스트와 튜플 모두 여러 개의 데이터를 저장한다는 공통점이 있다.

- 리스트 [] : 생성, 조회, 수정 가능
- 튜플 () : 생성, 조회 가능, 수정 불가능

```python

> tuple
```
```python
a[0] = 1

```

**6. 딕셔너리**
구분	표기	조회 방식	수정

>리스트 []
 - 생성, 조회, 수정, 삭제 가능
 - 조회 : 인덱스(정수) 이용
 
>튜플 ()
 - 생성, 조회, 가능, 수정 불가
 - 조회 : 인덱스(정수) 이용
 
>딕셔너리 {키 : 값}
 - 생성, 조회 수정 등 가능
 - 조회 : 인덱스가 아닌 키를 이용
 - 값에는 튜플, 리스트 다 들어갈 수 있음



```python
dic = {"one": 1, "two": 2, "three": 3}
lst = [1, 2, 3]
tup = (1, 2, 3)

# 조회
dic["one"], lst[0], tup[0]
> (1, 1, 1)
```
```
# 수정
lst[0] = 10
dic["one"] = 10
> tup[0] = 10  → 오류 발생
```
- 리스트는 인덱스로, 딕셔너리는 키로 데이터를 식별
- 딕셔너리는 각 데이터에 이름을 붙여 사람이 이해하기 쉽게 저장할 수 있다는 장점


```python
info = {
    "a": 1,
    "b": 3.14,
    "c": "Hello",
    "d": True,
    "e": None,
    "f": [1, 2, 3],
    "g": (4, 5, 6),
    "h": {"key": "value"}
}
```

**7. 집합**
{ }로 표기하며 중복을 허용하지 않음
```python
a = [1, 1, 1, 2, 2, 2, 2]          # 리스트
b = (1, 1, 1, 2, 2, 2, 2)          # 튜플
d = {1, 1, 1, 1, 2, 2, 2, 2}       # 집합

print(a)  # [1, 1, 1, 2, 2, 2, 2]
print(b)  # (1, 1, 1, 2, 2, 2, 2)
print(d)  # {1, 2}   ← 중복이 자동으로 제거됨
```

- elif - 조건은 타이트한 순서부터

⚠️ 조건 순서를 잘못 잡으면(느슨한 조건이 먼저 오면) 오류는 안 나지만 의도한 대로 동작하지 않음. 항상 타이트한 조건부터 작성!

```python

```

>or : 둘 중 하나만 참이어도 참
and : 둘 다 참이어야 참
not : 참/거짓 반전


``` python
x, y = True, False

if x and y:
    print(1111)
else:
    print(2222)    # 2222
    
```

**10. 반복문**
기본 for문 + 구구단


```python
x = 2
for i in range(1, 10):
    print(f"{x} * {i} = {x * i}")
    
```
> x는 고정된 변수
i는 반복될 때마다 값이 바뀌는 변수

<br>
- 조건 + 반복 (짝수만 출력)

```python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
> 2 * 2 = 4
> 2 * 4 = 8

```

-break / continue / pass

```python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
        break     # 조건 만족 시 반복문 즉시 종료
> 2 * 2 = 4  (한 번만 출력되고 멈춤)

for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        continue  # 이후 코드는 건너뛰고 다음 반복으로
        print("실행되지 않음")
 
```
<br>

- for-else

else는 반복문이 break 없이 정상적으로 끝까지 실행됐을 때만 실행 (오늘 처음 배운 개념...)


```python
for i in [1, 2, 3, 4, 5]:
    if i % 2 == 0:
        print(f"{x} * {i} = {x * i}")
else:
    print("for문이 정상적으로 종료됨")

```
>for문은 반복 횟수를 미리 알 때 사용
while문은 반복을 언제까지 할지 모를 때 사용

**11. 예외처리**

대표적인 예외(Exception) 종류: NameError, IndexError, KeyError, ZeroDivisionError, TypeError, ValueError

- try / except

```python
try:
    x = int('11')
    print(x)
except ValueError as e:
    print(f'오류 메세지: {e}')

```
여러 예외를 각각 처리할 수 있음


```python
try:
    x = [1, 2, 3]
    x.append(4)
    x + 'aa'
except ValueError as e:
    print(f'오류명: {type(e)} / 메세지: {e}')
except TypeError as e:
    print(f'오류명: {type(e)} / 메세지: {e}')
> 오류명: <class 'TypeError'> / 메세지: can only concatenate list (not "str") to list

```
<br>
- else / finally

```python
x = 10

try:
    print(f"{int(x)}는 숫자입니다.")
except ValueError as e:
    print("오류입니다.")
else:      # try문이 문제없이 끝났을 때만 실행
    print("나 왔어~")
finally:   # 오류 발생 여부와 상관없이 항상 실행
    print("오류가 발생하든 안하든 무조건 실행하는 것")
```    

- assert

특정 조건이 False일 때 강제로 에러를 발생시킨다.


```python
x = 2
assert x % 3 == 0, "오류입니다."
print("오류가 아닙니다.")
> AssertionError: 오류입니다.

```

- raise

```python
x = 2
if x % 3 != 0:
    raise Exception("오류입니다.")
else:
    print("오류가 아닙니다.")
> Exception: 오류입니다.

```
