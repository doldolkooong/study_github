# 숫자 맞추기 게임

[원문 보기](https://velog.io/@doldolkoong/%EC%88%AB%EC%9E%90-%EB%A7%9E%EC%B6%94%EA%B8%B0-%EA%B2%8C%EC%9E%84) · 2026-09-08 정리

> [!tip] 핵심
> 입력 변환·범위 검사·시도 횟수·종료 조건을 분리해 숫자 맞추기를 완성한다.

## <문제>

입력 변환·범위 검사·시도 횟수·종료 조건을 분리해 숫자 맞추기를 완성한다.

### 입력 / 조건

- random.randint(1,100)으로 게임 시작 전에 한 번 정답을 뽑는다.
- 문자열을 정수로 바꿀 수 있는지와 1~100 범위인지를 따로 검사한다.
- 잘못된 입력은 continue, 정답은 break로 처리한다.
- 보완 예제는 유효한 범위의 정수 입력만 시도 횟수에 포함한다.

### 출력 / 요구사항

정답과 비교해 힌트를 주거나 횟수를 출력하고 종료한다.

### 예시

```text
정답을 50으로 고정한 경우:
입력 abc → 정수 안내
입력 0 → 범위 안내
입력 30 → UP
입력 70 → DOWN
입력 50 → 정답! 3번 만에 맞혔습니다.
```

## <코드>

### 내가 작성한 코드

원문에 게시한 코드 전체다. 원문의 오류 가능성도 보완 코드와 비교한다.

```python
import random

#1. 랜덤 숫자 만들기
answer = random.randint(1, 100)
count = 0

print("<숫자 맞추기 게임> \n 1~100 사이의 숫자를 맞춰보세요!")

#2. 사용자에게 숫자 입력 받기

while True:
    user = int(input("숫자를 입력하세요: "))

    #3. 1~100 사이의 숫자를 입력하도록 하는 문구 출력
    if user > 100:
        print("1~100 사이의 숫자를 입력해주세요.")
        continue
    
    #4. 정답을 맞추기 위해 시도했던 횟수 확인
    count += 1

    #5. 정답보다 크고 작은지 판단
    if user > answer: # 정답보다 클 경우
        print("========================")
        print(f"입력한 숫자 : {user}")
        print("더 작은 숫자입니다.")

    elif user < answer: # 정답보다 작을 경우
        print("========================")
        print(f"입력한 숫자 : {user}")
        print("더 큰 숫자입니다.")

    else: # 정답일 경우
        print("========================")
        print(f"숫자 입력 : {user}")
        print("🎉 정답입니다!")
        print(f"{count}번 만에 맞혔습니다!")
        break # 정답일 경우 반복 종료
        
```

### 수정한 코드 / 최종 코드

**정리 과정에서 제안한 보완 예제**

```python
import random
answer = random.randint(1, 100)
count = 0
while True:
    try:
        user = int(input('1~100 숫자: '))
    except ValueError:
        print('정수를 입력해주세요.')
        continue
    if not 1 <= user <= 100:
        print('1~100 사이의 숫자를 입력해주세요.')
        continue
    count += 1
    if user < answer:
        print('UP')
    elif user > answer:
        print('DOWN')
    else:
        print(f'정답! {count}번 만에 맞혔습니다.')
        break
```

출력은 정답 50을 가정한 흐름 예시다. 실제 게임은 랜덤 정답이므로 결과가 달라진다.

## <해설>

### 문제 핵심

| 개념 | 설명 |
|---|---|
| 정답 생성 | random.randint(1,100)으로 게임 시작 전에 한 번 정답을 뽑는다. |
| 입력 검증 | 문자열을 정수로 바꿀 수 있는지와 1~100 범위인지를 따로 검사한다. |
| 반복 제어 | 잘못된 입력은 continue, 정답은 break로 처리한다. |
| 횟수 정의 | 보완 예제는 유효한 범위의 정수 입력만 시도 횟수에 포함한다. |
| 비교 결과 | 입력이 정답보다 작으면 UP, 크면 DOWN을 안내한다. |

### 풀이 순서

1. 정답을 한 번 만들고 횟수를 0으로 초기화한다.
2. 입력 형변환과 하한·상한을 검사한 뒤 유효한 시도만 센다.
3. 정답과 비교해 힌트를 주거나 횟수를 출력하고 종료한다.

| 핵심 처리 | 입력 형변환과 하한·상한을 검사한 뒤 유효한 시도만 센다. |
| 결과 반환·출력 | 정답과 비교해 힌트를 주거나 횟수를 출력하고 종료한다. |

### 왜 이렇게 풀었는가?

입력 변환·범위 검사·시도 횟수·종료 조건을 분리해 숫자 맞추기를 완성한다. 1 <= user <= 100로 양쪽 경계 검사. 변환만 try/except로 감싸고 재입력.

### 막힌 부분 / 실수

| 증상 | 원인 | 보완 |
|---|---|---|
| 0·음수도 횟수에 포함 | 원문은 100 초과만 검사 | 1 <= user <= 100로 양쪽 경계 검사 |
| 문자 입력 시 프로그램 종료 | int 변환의 ValueError 미처리 | 변환만 try/except로 감싸고 재입력 |

- 잘못된 입력은 continue, 정답은 break로 처리한다.
- 보완 예제는 유효한 범위의 정수 입력만 시도 횟수에 포함한다.
