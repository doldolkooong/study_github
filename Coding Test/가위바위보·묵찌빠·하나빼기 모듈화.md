# 가위바위보·묵찌빠·하나빼기 모듈화

[원문 보기](https://velog.io/@doldolkoong/%EA%B0%80%EC%9C%84%EB%B0%94%EC%9C%84%EB%B3%B4-%EB%AC%B5%EC%B0%8C%EB%B9%A0-%ED%95%98%EB%82%98%EB%B9%BC%EA%B8%B0-%EB%AA%A8%EB%93%88%ED%99%94) · 2026-09-08 정리

> [!tip] 핵심
> Enum·공통 입력·결과 반환을 활용해 세 게임을 조합하고 묵찌빠의 공격권을 상태로 관리한다.

## <문제>

Enum·공통 입력·결과 반환을 활용해 세 게임을 조합하고 묵찌빠의 공격권을 상태로 관리한다.

### 입력 / 조건

- 가위=1·바위=2·보=0일 때 차이의 나머지로 승패를 구한다.
- constants·inputs·게임 로직·prints·main을 분리한다.
- 게임 결과·User 선택·Computer 선택 키로 결과를 전달한다.
- 공격권이 없는 시작 상태와 공격권을 정한 뒤의 무승부를 구별해야 한다.

### 출력 / 요구사항

동일한 키의 결과를 반환하고 main에서 출력한다.

### 예시

```text
첫 가위바위보가 무승부면 공격권을 정하지 않고 다시 입력받는다.
```

## <코드>

### 내가 작성한 코드

원문에 게시한 코드 중 constants.py다. 원문의 오류 가능성도 보완 코드와 비교한다.

```python
from __future__ import annotations
import enum

# 가위 바위 보 저장한 상수
# 가위 바위 보 낸 것을 토대로 게임 결과를 저장하는 함수 생성
class rock_sissor_paper(enum.Enum):
    가위 = 1
    바위 = 2
    보 = 0

    def is_win(self, computer : rock_sissor_paper) -> str:
        result = (self.value - computer.value) % 3

        return game_result(result).name

# 게임 결과를 저장한 상수 game_result
# 1이면 이김, 2면 짐, 0이면 비김
class game_result(enum.Enum):
    win = 1 
    lose = 2
    draw = 0

# 게임 종류 상수
class game_type(enum.Enum):
    가위바위보 = enum.auto()
    하나빼기 = enum.auto()
    묵찌빠 = enum.auto()

# 묵찌빠 공격권 괸련 상수
class mukchippa_attack(enum.Enum):
    user_attack = 1
    user_shield = 0

	# 가위바위보 이겼으면 사용자 공격, 졌으면 사용자 수비
    def get_attacker(self, result):
        if result == game_result.win.name:
            return self.user_attack
        elif result == game_result.lose.name:
            return self.user_shield
        return self
```

### 수정한 코드 / 최종 코드

**정리 과정에서 제안한 보완 예제**

```python
def get_user_input():
    while True:
        value = input('가위, 바위, 보: ').strip()
        if value in rock_sissor_paper.__members__:
            return rock_sissor_paper[value]
        print('다시 선택해주세요.')

# 묵찌빠: 첫 공격권은 승패가 나온 후 정한다.
attacker = None
while attacker is None:
    user = get_user_input()
    computer = random.choice(list(rock_sissor_paper))
    result = user.is_win(computer)
    if result == 'win':
        attacker = mukchippa_attack.user_attack
    elif result == 'lose':
        attacker = mukchippa_attack.user_shield
```

원문 Enum과 random import를 전제로 한 교체용 보완 코드다. 전체 게임의 실행 완료를 주장하는 코드는 아니다.

## <해설>

### 문제 핵심

| 개념 | 설명 |
|---|---|
| Enum | 가위=1·바위=2·보=0일 때 차이의 나머지로 승패를 구한다. |
| 모듈 책임 | constants·inputs·게임 로직·prints·main을 분리한다. |
| 공통 계약 | 게임 결과·User 선택·Computer 선택 키로 결과를 전달한다. |
| 묵찌빠 상태 | 공격권이 없는 시작 상태와 공격권을 정한 뒤의 무승부를 구별해야 한다. |
| 입력 검증 | 잘못된 입력 재시도는 깊어지는 재귀보다 반복문으로 구성할 수 있다. |

### 풀이 순서

1. 게임 종류와 사용자 입력을 검증하여 Enum으로 바꾼다.
2. 선택한 게임 규칙에 따라 승패·공격권·재선택을 처리한다.
3. 동일한 키의 결과를 반환하고 main에서 출력한다.

### 코드 설명

| 코드의 역할 | 설명 |
|---|---|
| 입력 검증 | while 반복으로 검증 |
| 핵심 처리 | 선택한 게임 규칙에 따라 승패·공격권·재선택을 처리한다. |
| 결과 반환·출력 | 동일한 키의 결과를 반환하고 main에서 출력한다. |

### 왜 이렇게 풀었는가?

Enum·공통 입력·결과 반환을 활용해 세 게임을 조합하고 묵찌빠의 공격권을 상태로 관리한다. attacker=None으로 시작해 승패가 날 때까지 재시도. while 반복으로 검증.

### 막힌 부분 / 실수

| 증상 | 원인 | 보완 |
|---|---|---|
| 첫 무승부에 컴퓨터 공격권이 부여됨 | 초기값이 user_shield로 고정 | attacker=None으로 시작해 승패가 날 때까지 재시도 |
| 잘못된 입력 반복 시 재귀 깊이 증가 | 입력 함수가 자신을 다시 호출 | while 반복으로 검증 |
