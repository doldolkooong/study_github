## 🧩 Coding Test

프로그래머스 문제를 중심으로 풀이 과정을 기록합니다.

각 문제는 아래 구조로 정리합니다.

```markdown
## <문제>

문제 조건 및 요구사항

## <코드>

내가 작성한 코드
수정한 코드 / 최종 코드

## <해설>

문제 핵심
풀이 순서
코드 설명
막힌 부분 / 실수
기억할 내용
```

단순히 정답 코드만 남기기보다 **왜 이렇게 풀었는지와 틀린 이유를 함께 기록하는 것**을 목표로 합니다.

## 📝 Note Style

학습 노트는 아래 흐름으로 정리합니다.

```text
한 줄 요약
    ↓
선행지식
    ↓
학습 목표
    ↓
핵심 개념
    ↓
왜 필요한가?
    ↓
동작 원리
    ↓
코드 / 공식
    ↓
결과 해석
    ↓
실수 / 디버깅
    ↓
핵심 정리
    ↓
복습
```

코드가 포함된 경우 가능한 한 **코드가 왜 동작하는지 설명하는 것**을 중요하게 생각합니다.
