## 1단원 — 핵심 정의 🟢 ⭐

### ① 무엇인가?

분석 질문에 맞는 그래프를 고르고 숫자 요약에서 보이지 않는 패턴을 해석한다.

### ② 왜 필요한가?

## 2단원 — 원리 / 동작 과정 🔵 ⭐

### ① 전체 흐름

1. 변수의 수치·범주 여부와 비교 질문을 정한다.
2. 그래프와 축·단위·범례를 지정하고 분포 또는 관계를 그린다.
3. 통계값과 표본 수를 대조하며 이상치와 후속 분석 질문을 기록한다.

### ② 왜 이렇게 동작하는가?

Figure는 전체 그림이고 Axes는 각 좌표 영역이다. IQR 바깥은 이상치 후보이며 Sweetviz는 모델 학습보다 자동 탐색 보고서에 해당한다.

## 3단원 — 코드 / 공식 🔵 ⭐

### ① 핵심 코드

> 아래는 원문의 개념을 작은 입력으로 재구성한 학습용 예제다. 원문 코드는 하단 원문에서 확인할 수 있다.

```python
import matplotlib.pyplot as plt
x = [1, 2, 3, 4]
y = [1, 4, 9, 16]
fig, ax = plt.subplots()
ax.scatter(x, y)
ax.set(xlabel='x', ylabel='y', title='Nonlinear relation')
plt.show()
```

### ② 코드 이해

| 읽는 순서 | 의미 |
|---|---|
| 입력과 전제 | 변수의 수치·범주 여부와 비교 질문을 정한다. |
| 처리 | 그래프와 축·단위·범례를 지정하고 분포 또는 관계를 그린다. |
| 결과 | 두 수치의 관계가 직선으로만 설명되지 않는다는 점을 확인하는 예제다. |
