## 1단원 — 핵심 정의 🟢 ⭐

### ① 무엇인가?

생존률을 성별·등급·연령·가족 규모로 나누고 표본 수와 교란 가능성까지 해석한다.

### ② 왜 필요한가?

데이터 크기·컬럼·결측치와 survived 빈도를 확인한다. mean과 count를 함께 읽고 인과 단정을 피하며 모델링 후보를 정한다. 이를 통해 관측 단위에서 해석의 한계까지 연결해 이해한다.

### ③ 쉽게 이해하기 🎨

> [!example] 비유
> 전체 성적표 한 장을 반별·과목별로 다시 펼쳐 평균 뒤의 차이를 찾는다.

### ④ 핵심 용어

| 용어 | 뜻과 적용 포인트 |
|---|---|
| 관측 단위 | 원문 데이터는 승객 891명과 15개 컬럼이며 survived가 목표 변수이다. |
| 그룹 평균 | 0/1인 survived의 평균은 생존률이다. 원문 전체 생존률은 약 38.4%이다. |
| 다변량 분석 | 성별과 객실 등급을 함께 나누면 단일 평균보다 구체적인 차이가 보인다. |
| 파생변수 | family_size = sibsp + parch + 1이며 연령대 구간화에서는 나이 결측을 먼저 처리한다. |
| 해석의 한계 | 운임·등급·성별의 관계를 함께 봐야 하며 높은 생존률만으로 원인을 단정할 수 없다. |

## 2단원 — 원리 / 동작 과정 🔵 ⭐

### ① 전체 흐름

1. 데이터 크기·컬럼·결측치와 survived 빈도를 확인한다.
2. 조건 필터링 → groupby → 가족 규모·연령대 생성 → pivot_table 순으로 분석한다.
3. mean과 count를 함께 읽고 인과 단정을 피하며 모델링 후보를 정한다.

### ② 왜 이렇게 동작하는가?

0/1인 survived의 평균은 생존률이다. 원문 전체 생존률은 약 38.4%이다. 운임·등급·성별의 관계를 함께 봐야 하며 높은 생존률만으로 원인을 단정할 수 없다.

## 3단원 — 코드 / 공식 🔵 ⭐

### ① 핵심 코드

> 아래는 원문의 개념을 작은 입력으로 재구성한 학습용 예제다. 원문 코드는 하단 원문에서 확인할 수 있다.

```python
import pandas as pd
df = pd.DataFrame({'sex': ['female','female','male','male'],
                   'survived': [1,1,1,0]})
print(df.groupby('sex')['survived'].agg(['count','mean']))
```

### ② 코드 이해

| 읽는 순서 | 의미 |
|---|---|
| 입력과 전제 | 데이터 크기·컬럼·결측치와 survived 빈도를 확인한다. |
| 처리 | 조건 필터링 → groupby → 가족 규모·연령대 생성 → pivot_table 순으로 분석한다. |
| 결과 | 설명용 4명 데이터의 결과다. 원문 Titanic 수치와 구분한다. 표본 2명의 100%는 모든 여성에 대한 보장이 아니다. |

### ③ 실행 결과

**예상 결과·해석 기준 — 실제 환경 실행 결과와 구분**

```text

sex
female      2   1.0
male        2   0.5
```
