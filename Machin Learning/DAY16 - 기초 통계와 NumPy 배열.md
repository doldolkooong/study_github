## 1단원 — 핵심 정의 🟢 ⭐

### ① 무엇인가?

스칼라·벡터·행렬을 배열로 표현하고 인덱싱·reshape·axis 연산을 익힌다.

### ② 왜 필요한가?

np.array로 배열을 만들고 ndim·shape·size·dtype를 확인한다. reshape와 축별 집계를 수행하고 예상 shape와 실제 값을 비교한다. 이를 통해 기초 통계에서 배열 변형까지 연결해 이해한다.

### ③ 쉽게 이해하기 🎨

### ④ 핵심 용어

| 용어 | 뜻과 적용 포인트 |
|---|---|
| 기초 통계 | 평균·표준편차는 중심과 퍼짐을 표현한다. 퍼짐이 작다는 사실만으로 좋은 데이터라고 할 수 없다. |
| 행렬 종류 | 정방·대각·단위·영·전치·대칭·직교행렬의 조건을 구분한다. |
| 배열 차원 | ndim은 축 개수, shape는 축별 크기, size는 전체 원소 수이다. |
| 인덱싱과 슬라이싱 | 정수 인덱싱은 해당 축을 제거하고 슬라이싱은 축을 유지한다. |
| 배열 변형 | reshape는 원소 수를 유지하며 합치기와 조건 인덱싱에는 shape 조건이 있다. |

## 2단원 — 원리 / 동작 과정 🔵 ⭐

### ① 전체 흐름

1. np.array로 배열을 만들고 ndim·shape·size·dtype를 확인한다.
2. 정수 인덱싱과 슬라이싱 결과의 차원을 비교한다.
3. reshape와 축별 집계를 수행하고 예상 shape와 실제 값을 비교한다.

### ② 왜 이렇게 동작하는가?

정방·대각·단위·영·전치·대칭·직교행렬의 조건을 구분한다. reshape는 원소 수를 유지하며 합치기와 조건 인덱싱에는 shape 조건이 있다.

## 3단원 — 코드 / 공식 🔵 ⭐

### ① 핵심 코드

> 아래는 원문의 개념을 작은 입력으로 재구성한 학습용 예제다. 원문 코드는 하단 원문에서 확인할 수 있다.

```python
import numpy as np
a = np.arange(6).reshape(2, 3)
print(a.shape)
print(a.sum(axis=0).tolist())
print(a.sum(axis=1).tolist())
```

### ② 코드 이해

| 읽는 순서 | 의미 |
|---|---|
| 입력과 전제 | np.array로 배열을 만들고 ndim·shape·size·dtype를 확인한다. |
| 처리 | 정수 인덱싱과 슬라이싱 결과의 차원을 비교한다. |
| 결과 | axis=0 집계는 행 축을 줄여 열 3개가 남고 axis=1은 열 축을 줄여 행 2개가 남는다. |

### ③ 실행 결과

**예상 결과·해석 기준 — 실제 환경 실행 결과와 구분**

```text
(2, 3)
[3, 5, 7]
[3, 12]
```

### ④ 결과 해석

axis=0 집계는 행 축을 줄여 열 3개가 남고 axis=1은 열 축을 줄여 행 2개가 남는다.
