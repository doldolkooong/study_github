## 1단원 — 핵심 정의 🟢 ⭐

### ① 무엇인가?

데이터의 의미와 분포를 점검한 뒤 결측 원인에 맞춰 정제 방법을 선택한다.

### ② 왜 필요한가?

shape·info·describe·빈도·결측률로 상태를 확인한다. 결측 원인과 분포에 맞는 처리를 선택하고 처리 전후를 비교한다. 이를 통해 형태와 의미에서 대체 방법까지 연결해 이해한다.

### ③ 쉽게 이해하기 🎨

> [!example] 비유
> 빈칸을 무조건 같은 숫자로 채우기 전에 왜 비었는지 조사한다.

### ④ 핵심 용어

| 용어 | 뜻과 적용 포인트 |
|---|---|
| 형태와 의미 | 정형·반정형·비정형을 구분하고 dtype와 수치형·범주형 의미를 별도로 판단한다. |
| 통계와 시각화 | 상관계수·왜도·첨도·Box Plot을 함께 확인한다. pandas 첨도는 초과첨도 기준이다. |
| 로그 변환 | fare처럼 오른쪽 꼬리가 긴 값에 log1p를 적용해 분포 변화를 확인한다. |
| 결측 메커니즘 | MCAR·MAR·MNAR는 결측 발생과 관측 변수·누락 값의 관계를 구분한다. |
| 대체 방법 | 평균·중앙값·랜덤·그룹별·KNN 대체의 왜곡과 비용을 비교한다. |

## 2단원 — 원리 / 동작 과정 🔵 ⭐

### ① 전체 흐름

1. shape·info·describe·빈도·결측률로 상태를 확인한다.
2. 상관행렬·분포·이상치 후보와 중복 의미 컬럼을 확인한다.
3. 결측 원인과 분포에 맞는 처리를 선택하고 처리 전후를 비교한다.

### ② 왜 이렇게 동작하는가?

상관계수·왜도·첨도·Box Plot을 함께 확인한다. pandas 첨도는 초과첨도 기준이다. 평균·중앙값·랜덤·그룹별·KNN 대체의 왜곡과 비용을 비교한다.

### ③ 그림으로 설명

```mermaid
    A["형태와 의미"] --> B["통계와 시각화"] --> C["대체 방법"]
```

## 3단원 — 코드 / 공식 🔵 ⭐

### ① 핵심 코드

> 아래는 원문의 개념을 작은 입력으로 재구성한 학습용 예제다. 원문 코드는 하단 원문에서 확인할 수 있다.

```python
import pandas as pd
s = pd.Series([20, 30, 100, None])
print(s.fillna(s.median()).tolist())
print(s.isna().mean())
```

### ② 코드 이해

| 읽는 순서 | 의미 |
|---|---|
| 입력과 전제 | shape·info·describe·빈도·결측률로 상태를 확인한다. |
| 처리 | 상관행렬·분포·이상치 후보와 중복 의미 컬럼을 확인한다. |
| 결과 | 중앙값 30으로 하나의 결측을 채웠다. 이는 방법 설명용이며 모델링에서는 Train의 중앙값을 따로 학습한다. |

### ③ 실행 결과

**예상 결과·해석 기준 — 실제 환경 실행 결과와 구분**

```text
[20.0, 30.0, 100.0, 30.0]
0.25
```

### ④ 결과 해석

중앙값 30으로 하나의 결측을 채웠다. 이는 방법 설명용이며 모델링에서는 Train의 중앙값을 따로 학습한다.
