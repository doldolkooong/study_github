## 1단원 — 핵심 정의 🟢 ⭐

### ① 무엇인가?

MSE의 기울기로 회귀 파라미터를 갱신하고 분류 오류를 혼동행렬과 임계값으로 분석한다.

### ② 왜 필요한가?

X·y와 초기 w·b를 정하고 예측 오차를 계산한다. 분류에서는 혼동행렬·Precision·Recall·F1을 계산하고 오류 비용에 맞는 임계값을 검토한다. 이를 통해 선형 회귀에서 임계값과 AUC까지 연결해 이해한다.

### ③ 쉽게 이해하기 🎨

> [!example] 비유
> 경사하강법은 경사진 지형에서 발밑 기울기를 보고 낮은 쪽으로 조금씩 이동하는 과정이다.

### ④ 핵심 용어

| 용어 | 뜻과 적용 포인트 |
|---|---|
| 선형 회귀 | 예측식은 y_hat = wx + b이며 w와 b는 학습할 파라미터이다. |
| MSE와 Gradient | 오차 제곱의 평균을 줄이도록 dw = 2·mean((y_hat-y)·x), db = 2·mean(y_hat-y)를 계산한다. |
| 학습률과 규제 | 학습률은 갱신 폭, L1·L2 규제는 가중치에 부과하는 벌점이다. |
| 혼동행렬 | 행=실제, 열=예측이고 labels=[0,1]이면 TN·FP / FN·TP 순서다. Positive의 의미부터 확인한다. |
| 임계값과 AUC | 임계값에 따라 FP·FN이 달라진다. ROC는 FPR과 TPR, AUC는 점수의 순위 구분 능력을 요약한다. |

## 2단원 — 원리 / 동작 과정 🔵 ⭐

### ① 전체 흐름

1. X·y와 초기 w·b를 정하고 예측 오차를 계산한다.
2. MSE와 기울기를 구해 w -= lr*dw, b -= lr*db로 갱신한다.
3. 분류에서는 혼동행렬·Precision·Recall·F1을 계산하고 오류 비용에 맞는 임계값을 검토한다.

### ② 왜 이렇게 동작하는가?

오차 제곱의 평균을 줄이도록 dw = 2·mean((y_hat-y)·x), db = 2·mean(y_hat-y)를 계산한다. 임계값에 따라 FP·FN이 달라진다. ROC는 FPR과 TPR, AUC는 점수의 순위 구분 능력을 요약한다.

## 3단원 — 코드 / 공식 🔵 ⭐

### ① 핵심 코드

> 아래는 원문의 개념을 작은 입력으로 재구성한 학습용 예제다. 원문 코드는 하단 원문에서 확인할 수 있다.

```python
x, y = [1, 2], [50, 60]
w, b, lr = 0.0, 0.0, 0.01
errors = [w * a + b - t for a, t in zip(x, y)]
dw = 2 * sum(e*a for e,a in zip(errors,x)) / len(x)
db = 2 * sum(errors) / len(x)
w -= lr * dw
b -= lr * db
print(round(w, 2), round(b, 2))
```

### ② 코드 이해

| 읽는 순서 | 의미 |
|---|---|
| 입력과 전제 | X·y와 초기 w·b를 정하고 예측 오차를 계산한다. |
| 처리 | MSE와 기울기를 구해 w -= lr*dw, b -= lr*db로 갱신한다. |
| 결과 | 초기 예측이 실제보다 작아 기울기가 음수이고, 한 번 갱신하면 w와 b가 증가한다. 아직 최적해에 도달한 결과는 아니다. |

### ③ 실행 결과

**예상 결과·해석 기준 — 실제 환경 실행 결과와 구분**

```text
1.7 1.1
```

### ④ 결과 해석

초기 예측이 실제보다 작아 기울기가 음수이고, 한 번 갱신하면 w와 b가 증가한다. 아직 최적해에 도달한 결과는 아니다.

## 🔧 디버깅 포인트

| 증상 | 원인 | 해결 |
|---|---|---|
| Gradient를 더해서 손실 증가 | 최소화 방향의 부호를 잘못 적용 | 학습률×기울기를 뺀다 |
| 튜닝마다 Test 점수를 보고 모델 선택 | 평가 데이터를 개발에 반복 사용 | 검증 세트 또는 교차검증으로 선택하고 Test는 마지막 평가에 사용 |

## 🤖 ChatGPT 요약 붙여넣기

### 📚 이번 수업에서 배운 내용

- **선형 회귀**: 예측식은 y_hat = wx + b이며 w와 b는 학습할 파라미터이다.
- **MSE와 Gradient**: 오차 제곱의 평균을 줄이도록 dw = 2·mean((y_hat-y)·x), db = 2·mean(y_hat-y)를 계산한다.
- **학습률과 규제**: 학습률은 갱신 폭, L1·L2 규제는 가중치에 부과하는 벌점이다.
- **혼동행렬**: 행=실제, 열=예측이고 labels=[0,1]이면 TN·FP / FN·TP 순서다. Positive의 의미부터 확인한다.
- **임계값과 AUC**: 임계값에 따라 FP·FN이 달라진다. ROC는 FPR과 TPR, AUC는 점수의 순위 구분 능력을 요약한다.

2. 오차 제곱의 평균을 줄이도록 dw = 2·mean((y_hat-y)·x), db = 2·mean(y_hat-y)를 계산한다.
